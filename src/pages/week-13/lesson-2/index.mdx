## Namespace Requirement

`List<T>` lives in `System.Collections.Generic`.

```csharp
using System.Collections.Generic;
```

Without this namespace, `List<T>` is not recognized by the compiler.

---

## Core List\<T\> Operations

```csharp
using System.Collections.Generic;

List<Student> students = new List<Student>();
students.Add(new Student { Name = "Ada", Id = 1001, Gpa = 3.9 });
students.Add(new Student { Name = "Alan", Id = 1002, Gpa = 3.7 });

Console.WriteLine("Count: " + students.Count);

students.Remove(students[1]);
Console.WriteLine("Count after removal: " + students.Count);
```

## Foreach Integration with Week 12 Class Objects

`foreach` works directly with `List<Student>` and provides clean object traversal:

```csharp
List<Student> students = new List<Student>();
students.Add(new Student { Name = "Ada Lovelace", Id = 1001, Gpa = 3.9 });
students.Add(new Student { Name = "Grace Hopper", Id = 1003, Gpa = 4.0 });

foreach (Student student in students) {
    Console.WriteLine($"{student.Name} ({student.Id}) GPA: {student.Gpa}");
}
```

<div class="architect-rule">

### Senior Architect Perspective

Use `foreach` for full-sequence reads and reporting workflows. Use index-based loops only when positional mutation is required. This division improves readability and reduces off-by-one errors.
