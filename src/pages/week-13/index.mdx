## Collection Shift: Object Sets as First-Class Data

In Week 12, one variable referenced one object. In Week 13, one variable references a structured collection of objects. This shift enables bulk operations: reporting all students, removing specific records, and iterating every object using one loop construct.

<div class="architect-rule">

### Senior Architect Perspective

Collection choice is an architecture decision, not syntax trivia. Use arrays when capacity is fixed and index access is the primary concern. Use <code>List&lt;T&gt;</code> when the dataset changes at runtime and operational methods such as <code>.Add()</code> and <code>.Remove()</code> are required. In both models, the collection element type should be your custom class, not disconnected primitive variables.

</div>
