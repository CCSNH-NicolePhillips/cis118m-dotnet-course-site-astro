# Lab 08: The Robust Data Entry System

<DueDateBanner week={8} type="Lab" />

**Time: 45 minutes**  
**Points: 100**

## Mission Objective

You are building a **Daily Revenue Tracker** for a small business. The owner needs to enter revenue amounts for each day. Your program must **validate** each entry (reject negative numbers) and allow the owner to **signal they're done** by entering `0` (sentinel value). After processing, display a summary with total revenue, number of entries, and average.

---

## The Problem

The program accepts daily revenue entries in a loop. It must handle two critical scenarios:

<div class="ascii-art-box">
<pre>{`
   ┌───────────────────┐
   │  Prompt for input  │◄────────────────┐
   └────────┬──────────┘                  │
            │                              │
   ┌────────▼──────────┐     ┌──────────┐ │
   │  Input == 0 ?     │─YES─► BREAK    │ │
   └────────┬──────────┘     │ (exit)   │ │
            │ NO              └──────────┘ │
   ┌────────▼──────────┐                  │
   │  Input < 0 ?      │─YES─► Invalid!  ─┘
   └────────┬──────────┘      (continue)
            │ NO
   ┌────────▼──────────┐
   │  Add to total     │──────────────────┘
   │  Count entry      │
   └───────────────────┘
`}</pre>
</div>

1. **Validation**: If the user enters a **negative number**, print an error message and ask again (the entry is NOT counted)
2. **Sentinel**: When the user enters **0**, the loop terminates and the summary is displayed

## Example Output

**Normal Entry (Multiple Days):**
```
=== DAILY REVENUE TRACKER ===

Enter daily revenue (0 to finish): 1250.50
  ✓ Day 1: $1,250.50

Enter daily revenue (0 to finish): 980.75
  ✓ Day 2: $980.75

Enter daily revenue (0 to finish): -50
  ✗ Invalid: Revenue cannot be negative. Try again.

Enter daily revenue (0 to finish): 2100.00
  ✓ Day 3: $2,100.00

Enter daily revenue (0 to finish): 0

=== REVENUE SUMMARY ===
  Total Entries: 3
  Total Revenue: $4,331.25
  Average/Day:   $1,443.75
========================
```

**Immediate Exit (No Entries):**
```
=== DAILY REVENUE TRACKER ===

Enter daily revenue (0 to finish): 0

No revenue entries recorded.
```

**Multiple Validation Failures:**
```
=== DAILY REVENUE TRACKER ===

Enter daily revenue (0 to finish): -100
  ✗ Invalid: Revenue cannot be negative. Try again.

Enter daily revenue (0 to finish): -25.50
  ✗ Invalid: Revenue cannot be negative. Try again.

Enter daily revenue (0 to finish): 500
  ✓ Day 1: $500.00

Enter daily revenue (0 to finish): 0

=== REVENUE SUMMARY ===
  Total Entries: 1
  Total Revenue: $500.00
  Average/Day:   $500.00
========================
```
