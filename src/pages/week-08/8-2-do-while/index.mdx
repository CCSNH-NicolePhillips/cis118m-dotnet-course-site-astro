## 🧠 What Is a Do-While Loop?

A **do-while loop** executes the body **first**, then checks the condition. This guarantees at least one execution:

```csharp
string password;

do {
    Console.Write("Enter password: ");
    password = Console.ReadLine();
    
    if (password != "secret123") {
        Console.WriteLine("❌ Incorrect. Try again.");
    }
} while (password != "secret123");

Console.WriteLine("✅ Access granted!");
```

Notice the **semicolon after the closing parenthesis** — `while (condition);` — this is required and a common syntax mistake.

## 🔑 While vs. Do-While: When to Use Which

<div class="styled-table-container">
  <table>
    <thead>
      <tr>
        <th>Feature</th>
        <th>while</th>
        <th>do-while</th>
      </tr>
    </thead>
    <tbody>
      <tr>
        <td><strong>Check location</strong></td>
        <td>Before body (pre-check)</td>
        <td>After body (post-check)</td>
      </tr>
      <tr>
        <td><strong>Minimum executions</strong></td>
        <td>Zero — body may never run</td>
        <td>One — body always runs once</td>
      </tr>
      <tr>
        <td><strong>Best for</strong></td>
        <td>Conditions that might be false initially</td>
        <td>Input prompts, menus, "retry until valid"</td>
      </tr>
      <tr>
        <td><strong>Trailing semicolon</strong></td>
        <td>No semicolon after <code>)</code></td>
        <td>Semicolon required: <code>while (cond);</code></td>
      </tr>
    </tbody>
  </table>
</div>

<div class="pro-tip">
  <h3>💡 The Simple Rule</h3>
  <p>If you need to <strong>get user input</strong> before you can check it, use <code>do-while</code>. If the condition can be evaluated <strong>before the first iteration</strong>, use <code>while</code>.</p>
</div>

## Try It: Password Retry System

Implement a password validation loop — the user is prompted until the input matches:

<TryItNowRunner 
  starterId="week-08-lesson-1" 
  height={520}
  code={`using System;

class Program
{
    static void Main()
    {
        Console.WriteLine("=== SECURE ACCESS TERMINAL ===");
        Console.WriteLine("  System requires authentication.\\n");
        
        // The correct password
        const string CORRECT_PASSWORD = "alpha42";
        
        string input;
        int attempts = 0;
        const int MAX_ATTEMPTS = 3;

        do {
            attempts++;
            Console.Write($"  Attempt {attempts}/{MAX_ATTEMPTS} — Enter password: ");
            input = Console.ReadLine();
            
            if (input != CORRECT_PASSWORD) {
                int remaining = MAX_ATTEMPTS - attempts;
                if (remaining > 0) {
                    Console.WriteLine($"  ❌ Incorrect. {remaining} attempt(s) remaining.\\n");
                } else {
                    Console.WriteLine("  ❌ Incorrect.");
                }
            }
        } while (input != CORRECT_PASSWORD && attempts < MAX_ATTEMPTS);
        
        Console.WriteLine();
        if (input == CORRECT_PASSWORD) {
            Console.WriteLine("  ✅ ACCESS GRANTED");
            Console.WriteLine($"  Authenticated on attempt {attempts}.");
        } else {
            Console.WriteLine("  🔒 ACCOUNT LOCKED");
            Console.WriteLine($"  {MAX_ATTEMPTS} failed attempts. Contact admin.");
        }
        
        Console.WriteLine("\\n==============================");
    }
}`}

### Experiment: Explore Do-While Behavior

## 🔁 Do-While for Menu Systems

The do-while is the natural choice for interactive menus:

```csharp
int choice;

do {
    Console.WriteLine("\n=== MAIN MENU ===");
    Console.WriteLine("1. Start Game");
    Console.WriteLine("2. Load Save");
    Console.WriteLine("3. Settings");
    Console.WriteLine("0. Exit");
    Console.Write("Choice: ");
    
    choice = int.Parse(Console.ReadLine());
    
    switch (choice) {
        case 1: Console.WriteLine("Starting new game..."); break;
        case 2: Console.WriteLine("Loading save file..."); break;
        case 3: Console.WriteLine("Opening settings..."); break;
        case 0: Console.WriteLine("Goodbye!"); break;
        default: Console.WriteLine("Invalid choice!"); break;
    }
} while (choice != 0);
```

The menu **must appear at least once** — you can't ask the user to choose before showing them the options!

## ⚠️ Common Do-While Mistakes

<div class="styled-table-container">
  <table>
    <thead>
      <tr>
        <th>Mistake</th>
        <th>Problem</th>
        <th>Fix</th>
      </tr>
    </thead>
    <tbody>
      <tr>
        <td><strong>Missing semicolon</strong></td>
        <td><code>} while (cond)</code> → compile error</td>
        <td>Always end with <code>while (cond);</code></td>
      </tr>
      <tr>
        <td><strong>Using while instead</strong></td>
        <td>Variable not initialized before first check</td>
        <td>Use do-while when you need input first</td>
      </tr>
      <tr>
        <td><strong>No exit path</strong></td>
        <td>Condition never becomes false → infinite loop</td>
        <td>Ensure user can always reach the exit condition</td>
      </tr>
      <tr>
        <td><strong>Checking in wrong place</strong></td>
        <td>Duplicate validation inside body AND in condition</td>
        <td>Put the primary check in the <code>while</code> condition</td>
      </tr>
    </tbody>
  </table>
</div>

### 🎯 Predict the Output

What does this code print?

```csharp
int x = 10;

do {
    Console.WriteLine($"x = {x}");
    x += 5;
} while (x < 10);

Console.WriteLine($"Final: {x}");
```

<details class="predict-reveal">
<summary>Reveal Answer</summary>
<div class="predict-answer">

**Output:**
```
x = 10
Final: 15
```

The body runs **once** (printing `x = 10`), then `x` becomes 15. The condition `15 < 10` is false, so the loop exits. Even though `x` was already 10 (not less than 10) when the loop started, the body still ran because `do-while` checks **after** the body!

🔑 **Key takeaway**: With a `while` loop, this body would never run (10 is not < 10). The `do-while` guarantees one execution regardless of the initial condition.
