## 🛑 The `break` Statement

<img src="/media/week%208/8.3/The%20Sentinel%20Guard.jpeg" alt="The Sentinel Guard — a loop diagram showing break as an emergency exit that immediately terminates the loop when a sentinel value is encountered" style="max-width: 100%; border-radius: 12px; margin: 24px 0;" />

`break` immediately **exits the loop**, regardless of the loop condition:

```csharp
int i = 1;

while (true) {  // "infinite" loop — controlled by break
    Console.Write("Enter a number (0 to quit): ");
    int num = int.Parse(Console.ReadLine());
    
    if (num == 0) {
        break;  // Exit the loop immediately
    }
    
    Console.WriteLine($"  You entered: {num}");
    i++;
}

Console.WriteLine($"Processed {i - 1} numbers.");
```

The **sentinel value** (0 in this case) acts as a signal to stop processing. The `break` statement is the emergency exit.

## ⏭️ The `continue` Statement

`continue` **skips the rest of the current iteration** and jumps back to the condition check:

```csharp
int i = 0;

while (i < 10) {
    i++;
    
    if (i % 3 == 0) {
        continue;  // Skip multiples of 3
    }
    
    Console.WriteLine($"Processing: {i}");
}
```

**Output:**
```
Processing: 1
Processing: 2
Processing: 4
Processing: 5
Processing: 7
Processing: 8
Processing: 10
```

Numbers 3, 6, and 9 are skipped — `continue` jumps back to the `while` condition without executing `Console.WriteLine`.

<div class="pro-tip">
  <h3>💡 Break vs. Continue</h3>
  <p><code>break</code> = <strong>Exit the building</strong> — the loop is completely done.<br/>
  <code>continue</code> = <strong>Skip this floor</strong> — go to the next iteration immediately.</p>
</div>

## 🎯 Sentinel Values

A **sentinel value** is a special input that signals "stop processing." It's a value that <em>could never be valid data</em>:

```csharp
Console.WriteLine("Enter test scores (-1 to finish):");
int total = 0;
int count = 0;

while (true) {
    Console.Write("  Score: ");
    int score = int.Parse(Console.ReadLine());
    
    if (score == -1) {
        break;  // -1 is the sentinel — not a valid score
    }
    
    total += score;
    count++;
}

if (count > 0) {
    double average = (double)total / count;
    Console.WriteLine($"\nAverage of {count} scores: {average:F1}");
} else {
    Console.WriteLine("\nNo scores entered.");
}
```

<div class="architect-rule">

### ⚠️ Architect's Rule: Sentinel Values Must Be Invalid Data

Choose a sentinel that <strong>cannot</strong> be confused with real data:
- Scores? Use **-1** (scores can't be negative)
- Prices? Use **0** (nothing costs $0)
- Names? Use **empty string** or **"quit"**

If your sentinel could be valid data, your program has a bug!

</div>

  code={`using System;

class Program
{
    static void Main()
    {
        Console.WriteLine("=== DATA STREAM PROCESSOR ===");
        Console.WriteLine("  Processing sensor readings...\\n");
        
        // Simulated sensor data (normally from Console.ReadLine)
        int[] readings = { 42, 87, -5, 93, 0, 65, -12, 78, 55, 0 };
        
        int index = 0;
        int validCount = 0;
        int total = 0;
        int skipped = 0;
        
        while (index < readings.Length) {
            int reading = readings[index];
            index++;
            
            // Sentinel: 0 means "end of data stream"
            if (reading == 0) {
                Console.WriteLine($"  [{index}] ■ SENTINEL (0) — stopping stream");
                break;
            }
            
            // Skip negative readings (sensor errors)
            if (reading < 0) {
                Console.WriteLine($"  [{index}] ⚠ Negative reading ({reading}) — skipping");
                skipped++;
                continue;
            }
            
            // Process valid reading
            Console.WriteLine($"  [{index}] ✓ Valid reading: {reading}");
            total += reading;
            validCount++;
        }
        
        Console.WriteLine($"\\n  Summary:");
        Console.WriteLine($"  ─────────────────────");
        Console.WriteLine($"  Valid readings: {validCount}");
        Console.WriteLine($"  Skipped errors: {skipped}");
        if (validCount > 0) {
            Console.WriteLine($"  Average: {(double)total / validCount:F1}");
        }
        Console.WriteLine($"  Total processed: {total}");
    }
}`}

### 🎯 Predict the Output

What does this code print?

```csharp
int i = 0;
int sum = 0;

while (i < 8) {
    i++;
    
    if (i == 3) continue;
    if (i == 6) break;
    
    sum += i;
}

Console.WriteLine($"i = {i}, sum = {sum}");
```

<details class="predict-reveal">
<summary>Reveal Answer</summary>
<div class="predict-answer">

**Output**: `i = 6, sum = 12`

**Trace**:
- i=1: not 3, not 6 → sum = 0+1 = 1
- i=2: not 3, not 6 → sum = 1+2 = 3
- i=3: **continue** → skip sum, back to condition
- i=4: not 3, not 6 → sum = 3+4 = 7
- i=5: not 3, not 6 → sum = 7+5 = 12
- i=6: **break** → exit loop immediately

Sum = 1+2+4+5 = 12 (3 was skipped by continue, 6+ were stopped by break)

🔑 **Key takeaway**: `continue` skips ONE iteration. `break` stops ALL remaining iterations. Both are applied when they're encountered — order matters!
