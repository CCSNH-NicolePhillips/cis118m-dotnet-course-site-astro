# Week 08: While Loops

<DueDateBanner week={8} type="Lab" showLatePolicy={false} />

<div class="mission-brief">
  <h2>🔁 Iteration Unlocked</h2>
  <p>
    Up until now, your programs have been <strong>linear</strong> — every line runs once and the program marches forward. Decisions let you <em>choose</em> a path, but never revisit one. This week, that changes. You're installing the <strong>iteration engine</strong> — the ability to <strong>repeat</strong> blocks of code until a condition is met.
  </p>
  <p>
    Think of this as upgrading from a <strong>one-shot camera</strong> to a <strong>continuous sensor</strong>. A sensor doesn't read once and quit — it reads, checks, reads again, checks again. The <code>while</code> loop is your sensor. The <code>do-while</code> is your retry mechanism. And <code>break</code>/<code>continue</code> are your manual overrides.
  </p>
</div>

## 🧠 The Iteration Shift

Weeks 6-7 gave you decisions — `if`, `else`, `switch`. This week you add **repetition** — the ability to execute the same code multiple times:

<div class="ascii-art-box">
<pre>{`
   BEFORE (Linear)         AFTER (Iteration)
   ┌───────────┐           ┌───────────┐
   │ Statement │           │ Statement │
   └─────┬─────┘           └─────┬─────┘
   ┌─────▼─────┐           ┌─────▼─────┐
   │ Statement │           │ while (?) │◄──┐
   └─────┬─────┘           └─────┬─────┘   │
   ┌─────▼─────┐           ┌─────▼─────┐   │
   │ Statement │           │ loop body │───┘
   └─────┬─────┘           └─────┬─────┘
   ┌─────▼─────┐           ┌─────▼─────┐
   │   Done    │           │   Done    │

`}</pre>

## 🔧 The Iteration Toolkit

<div class="component-cards">
  <div class="component-card">
    <h5>🔁 while</h5>
    <p>Pre-check loop — checks condition <strong>before</strong> executing. Body may run 0 times.</p>
    <code>while (count &lt; 10) &#123; count++; &#125;</code>
  </div>
  <div class="component-card">
    <h5>🔄 do-while</h5>
    <p>Post-check loop — checks condition <strong>after</strong> executing. Always runs at least once.</p>
    <code>do &#123; input = ReadLine(); &#125; while (input != "quit");</code>
  </div>
  <div class="component-card">
    <h5>🛑 break</h5>
    <p>Emergency exit — immediately leaves the loop, no more iterations.</p>
    <code>if (value == 0) break;</code>
  </div>
  <div class="component-card">
    <h5>⏭️ continue</h5>
    <p>Skip this one — jumps to the next iteration, bypassing remaining body code.</p>
    <code>if (value &lt; 0) continue;</code>
  </div>
</div>
