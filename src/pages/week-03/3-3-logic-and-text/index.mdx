## Real-World Interaction Patterns

<div class="pattern-cards">
  <div class="pattern-card">
    <h4>Logic Gates</h4>
    <p>Bools are the 'gates.' If a gate is closed (<code>false</code>), the program execution path is blocked. This is the foundation of <code>if/else</code> branching.</p>
  </div>
  <div class="pattern-card">
    <h4>Data Carriers</h4>

  </div>
  <div class="pattern-card">
    <h4>The Dangerous Swap</h4>
    <p>Amateurs use strings for logic (e.g., <code>if (status == "Active")</code>). Professionals use bools or enums for speed and safety.</p>
  </div>
</div>

### Code in Action: The Pulse Drives the Story

Watch how a binary switch drives the complex string ribbon. One is the control, the other is the message.

```csharp
bool isSystemActive = true;
string userName = "Architect_Alpha";

if (isSystemActive) { // The gate is open! We can now process the text ribbon.
    string welcomeMessage = $"System online. Welcome, {userName}.";
    Console.WriteLine(welcomeMessage);
}
```

## ✅ bool: The Decision Type

A `bool` (Boolean) stores only two possible values: `true` or `false`. 

Named after mathematician George Boole, this type is the foundation of all computer logic.

```csharp
bool isSystemActive = true;
bool hasPermission = false;
bool isLoggedIn = true;
```

### Common Uses for bool:
- **System states:** Is the server online? Is the user authenticated?
- **Flags:** Should we enable this feature? Has the task completed?
- **Conditions:** Results of comparisons (covered in Week 06)

<TryItNowRunner 
  starterId="week-03-bool-demo" 
  height={320}
  code={`using System;

class Program
{
    static void Main()
    {
        bool isEngineRunning = true;
        bool isMaintenanceMode = false;
        
        Console.WriteLine("Engine Running: " + isEngineRunning);
        Console.WriteLine("Maintenance Mode: " + isMaintenanceMode);
        
        // Toggle the state
        isMaintenanceMode = true;
        Console.WriteLine("After toggle: " + isMaintenanceMode);
    }
}`}
  instructions="Run this code. Try changing the boolean values!"

### Default Value

If you declare a `bool` without initializing it (in a class field), its default value is `false`.

```csharp
bool isVerified;  // Default: false
```

## 🔤 char: The Single Character

A `char` stores exactly **one** Unicode character. Use single quotes!

```csharp
char grade = 'A';
char initial = 'J';
char symbol = '#';
char newline = '\n';  // Special escape character
```

### char vs string:
- `char` = Single quotes: `'A'`
- `string` = Double quotes: `"A"` (even for one character)

<TryItNowRunner 
  starterId="week-03-char-demo" 
  height={300}
  code={`using System;

class Program
{
    static void Main()
    {
        char letterGrade = 'A';
        char plusMinus = '+';
        
        Console.WriteLine("Your grade: " + letterGrade + plusMinus);
        
        // Each char is a single character
        char first = 'C';
        char second = '#';
        Console.WriteLine("Language: " + first + second);
    }
}`}
  instructions="Run this code. Notice how chars combine when concatenated!" 
/>

## 📝 string: The Text Type

A `string` is a sequence of characters—any text from a single word to an entire document.

```csharp
string greeting = "Hello, World!";
string empty = "";
string userName = "Alice";
```

## 🔒 String Immutability

<div class="critical-concept">
  <h3>⚡ Key Concept: Strings are Immutable</h3>
  <p>
    Once a string is created in memory, it <strong>cannot be changed</strong>. 
    Any operation that appears to modify a string actually creates a <strong>new string</strong>.
  </p>
</div>

### What Immutability Means

```csharp
string message = "Hello";
message = message + " World";  // Creates a NEW string in memory
```

<DeepDiveTabs
  title="String Immutability Explained"
  tabs={[
    {
      id: "visual",
      label: "📊 Visual Example",
      content: `
        <h3>Memory Before and After</h3>
        <pre>
Step 1: string message = "Hello";
Memory: [Hello] ← message points here

Step 2: message = message + " World";
Memory: [Hello] ← orphaned (garbage collected)
        [Hello World] ← message now points here
        </pre>
        <p>The original "Hello" isn't modified—a completely new string is created.</p>
      `
    },
    {
      id: "why",
      label: "❓ Why Immutability?",
      content: `
        <h3>Benefits of Immutable Strings</h3>
        <ul>
          <li><strong>Thread Safety:</strong> Multiple parts of your program can safely read the same string</li>
          <li><strong>Security:</strong> A string can't be changed after validation</li>
          <li><strong>Caching:</strong> Identical strings can share memory</li>
        </ul>
        <p><strong>Trade-off:</strong> Heavy string manipulation can create many temporary objects.</p>
      `
    }
  ]}
/>

## 🔗 String Concatenation

You can combine strings using the `+` operator:

```csharp
string first = "Hello";
string second = "World";
string combined = first + " " + second;  // "Hello World"
```

### String Interpolation (Modern C#)

A cleaner way to build strings:

<TryItNowRunner 
  starterId="week-03-interpolation" 
  height={320}
  code={`using System;

class Program
{
    static void Main()
    {
        string name = "Engineer";
        int level = 5;
        
        // Old way (concatenation)
        Console.WriteLine("Welcome, " + name + "! Level: " + level);
        
        // Modern way (interpolation with $)
        Console.WriteLine($"Welcome, {name}! Level: {level}");
    }
}`}
  instructions="The $ before the string allows you to embed variables in {curly braces}!" 
/>
