## 📤 Required Output Format

Your program output should follow this exact format:

```
=== PROJECT BUDGET ESTIMATOR ===
Enter project name: Website Redesign
Enter estimated hours: 120.5
Enter architect hourly rate: 85.00

=== BUDGET REPORT ===
Project Website Redesign requires $10,242.50 in funding.
================================
```

> **Note:** The dollar amount should be formatted as currency using `$"{total:C}"` or similar formatting.
