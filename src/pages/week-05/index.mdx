## 🎓 Learning Objectives

By the end of this week, you will be able to:

1. **Explain** why `Console.ReadLine()` is a blocking call that halts execution
2. **Capture** user input and store it in string variables
3. **Parse** text input into numeric types using `int.Parse()`, `double.Parse()`, `decimal.Parse()`
4. **Justify** why `decimal` is mandatory for financial calculations
5. **Build** an interactive console application that combines input, parsing, and output
