## 🧠 What is a Blocking Call?

A **blocking call** is an instruction that **halts the CPU thread** until some external event occurs. When you call `Console.ReadLine()`, the program stops executing and waits—potentially forever—until the user types something and presses **Enter**.

## 💻 Basic ReadLine Syntax

<TryItNowRunner 
  starterId="week-05-readline-basic" 
  height={350}
  enableInteractiveTerminal={true}
  code={`using System;

class Program
{
    static void Main()
    {
        // The program BLOCKS here until you type and press Enter
        Console.Write("Enter your name: ");  // No newline - cursor stays on same line
        string name = Console.ReadLine();    // BLOCKING CALL - waits for input
        
        // Code resumes ONLY after user presses Enter
        Console.WriteLine($"Hello, {name}!");
    }
}`}

      label: "Write vs WriteLine",
      content: `
        <h3>Console.Write() vs Console.WriteLine()</h3>
        <p>When prompting for input, use <code>Console.Write()</code> (no newline) so the cursor stays on the same line as your prompt:</p>
        <pre><code>Console.Write("Enter name: ");   // Cursor: "Enter name: |"
Console.WriteLine("Enter name:"); // Cursor moves to next line</code></pre>
        <p><strong>Professional practice:</strong> Use Write() for prompts so the user types on the same line.</p>
      `
    },
    {
      id: "null-string",
      label: "The Nullable String",
      content: `
        <h3>ReadLine Returns string?</h3>
        <p>Technically, <code>Console.ReadLine()</code> can return <code>null</code> if input is redirected. In modern C#, the return type is <code>string?</code> (nullable string):</p>
        <pre><code>string? input = Console.ReadLine();

// Safest practice:
string name = Console.ReadLine() ?? "";  // Default to empty if null</code></pre>
        <p>For this course, we'll use <code>string</code> since we're always getting keyboard input.</p>
      `
    },
    {
      id: "blocking-detail",
      label: "Why Blocking Matters",
      content: `
        <h3>Thread Suspension</h3>
        <p>When <code>ReadLine()</code> executes:</p>
        <ul>
          <li>The calling thread is <strong>suspended</strong></li>
          <li>CPU cycles are released (not spinning in a loop)</li>
          <li>The OS handles the keyboard buffer</li>
          <li>When Enter is pressed, the thread wakes up</li>
        </ul>
        <p><strong>In async programming (future courses),</strong> blocking is often avoided. For console apps, it's expected and appropriate.</p>
      `
    }
  ]}
