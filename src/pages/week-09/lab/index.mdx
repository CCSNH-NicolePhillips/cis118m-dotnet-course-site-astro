## Stage I: Multiplication Table Generator

**Specification:** Accept a target number from the user. Print its multiplication table from 1 through 10 using a `for` loop. Each line must follow the exact format shown.

### Stage I Requirements

<div class="styled-table-container">
  <table>
    <thead>
      <tr>
        <th>Requirement</th>
        <th>Details</th>
      </tr>
    </thead>
    <tbody>
      <tr>
        <td>Header</td>
        <td>Print <code>=== MULTIPLICATION TABLE ===</code></td>
      </tr>
      <tr>
        <td>Prompt</td>
        <td>Print <code>Enter a number:</code> and read user input with <code>int.Parse(Console.ReadLine())</code></td>
      </tr>
      <tr>
        <td>Loop structure</td>
        <td>Use a <code>for</code> loop. Counter runs from 1 through 10 inclusive.</td>
      </tr>
      <tr>
        <td>Output format</td>
        <td>Each line: <code>[number] x [i] = [result]</code></td>
      </tr>
      <tr>
        <td>Brace style</td>
        <td>K&amp;R — opening brace on same line as <code>for</code></td>
      </tr>
    </tbody>
  </table>
</div>

### Stage I Example Output

```
=== MULTIPLICATION TABLE ===
Enter a number: 7

7 x 1 = 7
7 x 2 = 14
7 x 3 = 21
7 x 4 = 28
7 x 5 = 35
7 x 6 = 42
7 x 7 = 49
7 x 8 = 56
7 x 9 = 63
7 x 10 = 70
```

## Stage II: Sum and Average Calculator

**Specification:** Accept a positive integer N from the user. Calculate the sum of all integers from 1 through N using an accumulator pattern. Calculate and display the average. Guard against integer division truncation.

### Stage II Requirements

<div class="styled-table-container">
  <table>
    <thead>
      <tr>
        <th>Requirement</th>
        <th>Details</th>
      </tr>
    </thead>
    <tbody>
      <tr>
        <td>Header</td>
        <td>Print <code>=== SUM AND AVERAGE ===</code></td>
      </tr>
      <tr>
        <td>Prompt</td>
        <td>Print <code>Enter N:</code> and read input</td>
      </tr>
      <tr>
        <td>Accumulator</td>
        <td>Declare <code>int sum = 0</code> before the loop</td>
      </tr>
      <tr>
        <td>Loop</td>
        <td>For loop from 1 to N inclusive, adding each i to sum</td>
      </tr>
      <tr>
        <td>Average</td>
        <td>Calculate as <code>(double)sum / n</code> — cast required</td>
      </tr>
      <tr>
        <td>Output</td>
        <td>Print sum as integer; average with two decimal places using <code>:F2</code></td>
      </tr>
    </tbody>
  </table>
</div>

### Stage II Example Output

```
=== SUM AND AVERAGE ===
Enter N: 10

Sum of 1 to 10: 55
Average: 5.50
```

## Stage III: Triangle Pattern Generator

**Specification:** Accept a positive integer N from the user. Print a right-triangle pattern of asterisks with N rows. Row 1 has 1 asterisk, row 2 has 2, up to row N. Each row occupies a distinct line. This requires nested for loops.

### Stage III Requirements

<div class="styled-table-container">
  <table>
    <thead>
      <tr>
        <th>Requirement</th>
        <th>Details</th>
      </tr>
    </thead>
    <tbody>
      <tr>
        <td>Header</td>
        <td>Print <code>=== TRIANGLE PATTERN ===</code></td>
      </tr>
      <tr>
        <td>Prompt</td>
        <td>Print <code>Enter height:</code> and read input</td>
      </tr>
      <tr>
        <td>Outer loop</td>
        <td>Controls the row number (1 through N). Variable: <code>row</code></td>
      </tr>
      <tr>
        <td>Inner loop</td>
        <td>Controls stars per row (1 through row). Variable: <code>col</code></td>
      </tr>
      <tr>
        <td>Star output</td>
        <td>Print each star with <code>Console.Write("* ")</code> — no newline inside inner loop</td>
      </tr>
      <tr>
        <td>Row end</td>
        <td>After inner loop completes, call <code>Console.WriteLine()</code> to advance to next line</td>
      </tr>
    </tbody>
  </table>
</div>

### Stage III Example Output

```
=== TRIANGLE PATTERN ===
Enter height: 5

* 
* * 
* * * 
* * * * 
* * * * * 
```

## Complete Program Requirements

Your submission must:

1. Run all three stages in a single `Program.cs` file under a single `Main` method.
2. Separate each stage with a blank line between the final output line of one stage and the header of the next.
3. Use `for` loops — not `while` loops — for all iteration.
4. Follow K&R brace style throughout.
5. Use `int.Parse(Console.ReadLine())` for all numeric input.
6. Cast to `double` before division in Stage II.
