## The Accumulator Pattern

The **accumulator pattern** requires three elements: a variable initialized before the loop, a loop that adds to it on each iteration, and a result read after the loop:

```csharp
// Calculate the sum of 1 through 100
int total = 0;  // 1. Accumulator — initialized BEFORE the loop

for (int i = 1; i <= 100; i++) {
    total += i;  // 2. Accumulate — i drives the value being added
}

// 3. Result — read AFTER the loop
Console.WriteLine($"Sum of 1 to 100: {total}");
// Output: Sum of 1 to 100: 5050
```

<div class="architect-rule">

### Architect's Rule: Accumulator Initialization

The accumulator **must** be initialized **before** the loop and read **after** the loop. Declaring it inside the loop body resets it to zero on every iteration — a critical logic error that produces the wrong result silently:

```csharp
// WRONG: accumulator reset on every iteration
for (int i = 1; i <= 5; i++) {
    int total = 0;   // ← This destroys the previous total every iteration!
    total += i;
    Console.WriteLine(total);  // prints 1, 2, 3, 4, 5 — never accumulates
}

// CORRECT: accumulator lives outside the loop
int total = 0;
for (int i = 1; i <= 5; i++) {
    total += i;
}
Console.WriteLine(total);  // prints 15 — the actual sum
```

## Calculating Averages

<img
  src="/media/week%209/9.2/Integer%20Division%20Trap.jpeg"
  alt="Before/after comparison: integer division truncates 7/2 to 3 versus casting to double preserves 3.5"
  style="width: 100%; max-width: 800px; border-radius: 10px; margin: 1rem auto; display: block;"
/>

An average requires two accumulators — or using the loop count itself as the divisor:

```csharp
int sum = 0;
int count = 10;

for (int i = 1; i <= count; i++) {
    sum += i;
}

// Integer division truncates! Cast to double for a precise average.
double average = (double)sum / count;
Console.WriteLine($"Sum: {sum}");
Console.WriteLine($"Average: {average:F2}");
// Output:
// Sum: 55
// Average: 5.50
```

When calculating averages, always cast to <code>double</code> before dividing: <code>(double)sum / count</code>. This is one of the most common precision errors in student code — and in production systems written by engineers who should know better. Validate your averages with known inputs before shipping any calculation.</p>

## The Index Pattern: Driving Logic with i

The counter variable `i` does not have to represent a generic count — it can represent **position**, **value**, or **logical state**. This is the **index pattern**:

```csharp
// Pattern 1: i represents a sequence value (sum of squares)
int sumOfSquares = 0;
for (int i = 1; i <= 5; i++) {
    sumOfSquares += i * i;  // i drives the calculation
}
Console.WriteLine($"Sum of squares: {sumOfSquares}");  // 55

// Pattern 2: i categorizes iterations (even vs odd)
for (int i = 1; i <= 10; i++) {
    if (i % 2 == 0) {
        Console.WriteLine($"{i} is even");
    } else {
        Console.WriteLine($"{i} is odd");
    }
}

// Pattern 3: i counts down (decrement)
Console.WriteLine("Countdown:");
for (int i = 5; i >= 1; i--) {
    Console.WriteLine($"T-minus {i}");
}
Console.WriteLine("Launch.");
```

Build a loop that calculates the sum and average of the numbers 1 through N:

<TryItNowRunner
  starterId="week-09-lesson-2"
  height={580}
  code={`using System;

class Program
{
    static void Main()
    {
        Console.WriteLine("=== SUM AND AVERAGE CALCULATOR ===");

        int n = 10;
        int sum = 0;  // accumulator

        for (int i = 1; i <= n; i++) {
            sum += i;
            Console.WriteLine($"  After i={i}: running total = {sum}");
        }

        double average = (double)sum / n;  // cast to avoid integer truncation

        Console.WriteLine($"\\nFinal Sum: {sum}");
        Console.WriteLine($"Average:   {average:F2}");
    }
}`}
