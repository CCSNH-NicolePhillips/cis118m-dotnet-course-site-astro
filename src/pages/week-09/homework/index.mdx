## Homework 09: The Loop Selection Analysis

<p>You have now worked with both <code>while</code> loops (Week 8) and <code>for</code> loops (Week 9). These are not equivalent tools — each is the correct instrument for a specific class of problems. This reflection requires you to demonstrate <strong>architectural decision-making</strong>: explaining not just how each loop works, but <em>when and why</em> to use each one. Engineering judgment, not just syntax recall.</p>
