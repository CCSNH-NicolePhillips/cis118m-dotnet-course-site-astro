# Lab 07: The Adaptive Firewall

<DueDateBanner week={7} type="Lab" />

**Time: 45 minutes**  
**Points: 100**

## 🎯 Mission Objective

You are building an **Adaptive Firewall** for a corporate network. The firewall evaluates three inputs — a **Threat Level** (integer), whether the source is **Internal** (boolean), and the **Protocol Type** (string) — and decides whether to **allow**, **require 2FA**, or **block** the connection. You'll use nested `if` statements, short-circuit `&&`, and `switch` to implement the decision engine.

---

## 📋 The Problem

The firewall must evaluate incoming network requests based on three pieces of data:

<img src="/media/week-7/lab/adaptiveFirewall.jpeg" alt="Adaptive Firewall Decision Engine diagram" style="max-width: 100%; border-radius: 8px; margin: 1rem 0;" />

The user enters a **threat level** (integer 1-10), whether the source is **internal** (true/false), and a **protocol** (string: HTTP, SSH, FTP, or SMTP). Your program must apply the firewall rules to determine the correct action.

Your program must:

## 📤 Example Output

**Critical Threat (Blocked):**
```
=== ADAPTIVE FIREWALL ===
Enter Threat Level (1-10): 9
Is source internal? (true/false): true
Enter Protocol (HTTP/SSH/FTP/SMTP): SSH

BLOCKED — Critical threat level
   Threat Level 9 exceeds maximum threshold.
   All connections blocked regardless of source.

Protocol Details (SSH):
   Port: 22
   Encryption: Required
============================
```

**Internal SSH (Allowed):**
```
=== ADAPTIVE FIREWALL ===
Enter Threat Level (1-10): 3
Is source internal? (true/false): true
Enter Protocol (HTTP/SSH/FTP/SMTP): SSH

ALLOWED — Trusted internal SSH
   Internal source verified with low threat.
   Secure shell session established.

Protocol Details (SSH):
   Port: 22
   Encryption: Required
============================
```

**Elevated Threat (2FA Required):**
```
=== ADAPTIVE FIREWALL ===
Enter Threat Level (1-10): 6
Is source internal? (true/false): false
Enter Protocol (HTTP/SSH/FTP/SMTP): HTTP

2FA REQUIRED — Elevated threat detected
   Threat Level 6 requires additional verification.
   Two-factor authentication challenge sent.

Protocol Details (HTTP):
   Port: 80/443
   Encryption: Optional (HTTPS recommended)
============================
```

**Default Deny:**
```
=== ADAPTIVE FIREWALL ===
Enter Threat Level (1-10): 2
Is source internal? (true/false): false
Enter Protocol (HTTP/SSH/FTP/SMTP): FTP

BLOCKED — Default deny policy
   External FTP connection denied.
   Contact network admin for access.

Protocol Details (FTP):
   Port: 21
   Encryption: None (not recommended)
============================
```
