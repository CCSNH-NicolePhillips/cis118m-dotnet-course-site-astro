## 🔧 The Advanced Logic Toolkit

<div class="component-cards">
  <div class="component-card">
    <h5>🏗️ Nested if</h5>
    <p>Decisions inside decisions — checking multiple layers of conditions.</p>
    <code>if (isLoggedIn) &#123; if (hasPermission) &#123; ... &#125; &#125;</code>
  </div>
  <div class="component-card">
    <h5>🛡️ Guard Clauses</h5>
    <p>Exit early to avoid deep nesting — keep code flat and readable.</p>
    <code>if (!isValid) return; // guard clause</code>
  </div>
  <div class="component-card">
    <h5>⚡ Short-Circuit</h5>
    <p><code>&&</code> stops if left is false. <code>||</code> stops if left is true.</p>
    <code>if (name != null && name.Length > 0)</code>
  </div>
  <div class="component-card">
    <h5>🔀 switch</h5>
    <p>Clean routing for matching a variable against specific values.</p>
    <code>switch (level) &#123; case 1: ... break; &#125;</code>
  </div>
</div>
