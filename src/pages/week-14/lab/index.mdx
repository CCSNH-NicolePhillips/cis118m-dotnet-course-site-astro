      <p>
        Sections 14.1 and 14.2 introduced the two architectural mechanisms that make classes self-defending: validated <code>set</code> accessors that reject invalid post-creation assignments, and overloaded constructors with <code>this()</code> chaining that enforce valid initial state at the moment of creation. This lab combines both. ## Mission Objective

Build a `Product` class that enforces its own state integrity through encapsulated properties and constructor overloading, then use it to build and report a product catalog stored in a `List<Product>`.

## Technical Requirements

<div class="styled-table-container">
  <table>
    <thead>
      <tr>
        <th scope="col">Requirement</th>
        <th scope="col">Details</th>
      </tr>
    </thead>
    <tbody>
      <tr>
        <td><strong>Private Backing Fields</strong></td>
        <td>Declare <code>private string _name</code>, <code>private double _price</code>, and <code>private int _stock</code> as the internal storage layer.</td>
      </tr>
      <tr>
        <td><strong>Validated Properties</strong></td>
        <td><code>Name</code>: reject empty/whitespace and trim. <code>Price</code>: reject negative values. <code>Stock</code>: reject negative values.</td>
      </tr>
      <tr>
        <td><strong>Computed Properties</strong></td>
        <td>Include <code>bool InStock</code> (derived from <code>_stock > 0</code>) and <code>double TotalValue</code> (derived from <code>_price * _stock</code>) with no backing fields.</td>
      </tr>
      <tr>
        <td><strong>Master Constructor</strong></td>
        <td>Write a three-parameter constructor <code>Product(string name, double price, int stock)</code> containing all validation logic and field assignments.</td>
      </tr>
      <tr>
        <td><strong>Constructor Overloads</strong></td>
        <td>Add a two-param <code>Product(string name, double price)</code> and a one-param <code>Product(string name)</code>, each using <code>: this(...)</code> to delegate to the master.</td>
      </tr>
      <tr>
        <td><strong>List Catalog</strong></td>
        <td>Create a <code>List&lt;Product&gt;</code>, add at least four products using different constructor overloads. Print <code>.Count</code> before and after removing one.</td>
      </tr>
      <tr>
        <td><strong>foreach Reporting</strong></td>
        <td>Use <code>foreach</code> to print each product's <code>Name</code>, <code>Price</code>, <code>Stock</code>, <code>InStock</code>, and <code>TotalValue</code> in a formatted output block.</td>
      </tr>
      <tr>
        <td><strong>Validation Demo</strong></td>
        <td>Include one <code>try/catch</code> block that attempts an invalid assignment (negative price or empty name) and prints the caught exception message.</td>
      </tr>
      <tr>
        <td><strong>Brace Style</strong></td>
        <td>K&amp;R style for all class definitions, constructors, and control structures.</td>
      </tr>
    </tbody>
  </table>
</div>
