# Written Final Guide: Deployment Memo

<div class="deadline-banner">
  <span class="deadline-label">If assigned:</span>
  <span>Include this memo inside the final project package by Saturday, May 9 at 11:59 PM Eastern</span>
</div>

<div class="support-note">
  <p>This page is support-only. It does not create a separate Week 15 homework grade.</p>
  <p>If your instructor wants a written final memo, include it as part of the final project package so the recorded score stays in the Final Project category.</p>
</div>

Answer every prompt in 3-5 sentences with specific technical reasoning if you need a written final artifact.

1. <strong>Architecture summary:</strong> Explain how your custom class architecture, encapsulated properties, <code>List&lt;T&gt;</code> data management, and modular methods interact during one normal operator workflow.
2. <strong>Verification strategy:</strong> Describe at least four tests you will run before submission, including at least two edge cases that could fail if the system is weakly designed.
3. <strong>Recovery-window triage:</strong> If you still have missing work from Weeks 01-14, identify exactly which items you will recover during the Week 15 window and how you will schedule them without undermining the capstone submission. If you have no missing work, state that explicitly.
4. <strong>Instructor runbook:</strong> Write the exact demonstration path an instructor should follow to verify your project in under five minutes, including which commands or menu options reveal the strongest architectural evidence.

<div class="architect-rule">
  <h3>Senior Architect Expectation</h3>
  <p>
    Your memo should sound like a deployment handoff document. Use concrete language: method names, object names, validation rules, and test scenarios. Avoid vague claims such as "it works" or "the code is organized." Explain how the system proves those claims.
  </p>
</div>

## Submission Note

- If you complete this memo, include it with the final project evidence package.
- The only graded Week 15 submission is the final project.
- There is no separate Week 15 lab or homework score.
