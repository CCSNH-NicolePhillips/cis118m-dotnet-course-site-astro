## Mission Objective

Build an integrated console deployment tracker that demonstrates a custom class, controlled validation, list-based storage, and method decomposition in one complete system.

## Technical Requirements

  <table>

      <tr>
        <th scope="col">Requirement</th>
        <th scope="col">Details</th>
      </tr>
    </thead>
    <tbody>
      <tr>
        <td>Custom class with guarded state</td>
        <td>A real class owns the deployment data and prevents invalid values from being stored.</td>
      </tr>
      <tr>
        <td>List-based workflow</td>
        <td>The program adds, stores, searches, or updates multiple deployment records in a <code>List&lt;T&gt;</code>.</td>
      </tr>
      <tr>
        <td>Named methods</td>
        <td>The controller loop delegates to methods such as add, list, search, or update instead of collapsing everything into <code>Main</code>.</td>
      </tr>
      <tr>
        <td>Readable runtime output</td>
        <td>The instructor can identify the successful path and the validation/failure path from the console output.</td>
      </tr>
    </tbody>
  </table>
