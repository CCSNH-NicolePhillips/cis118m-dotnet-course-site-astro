# Week 15 Extra Practice

Select one or two optional drills if you want a stronger deployment rehearsal.

1. Write a one-page interface map showing which method calls create objects, search the list, and print reports.
2. Build a manual verification matrix with at least six tests, including three edge cases.
3. Add one non-destructive update path to your system, such as editing a property through validated input.
4. If your project uses persistence, perform a cold-start test with no data file and a restart test with an existing data file.

These exercises are optional. They are intended to make the final submission more stable and easier to defend.
