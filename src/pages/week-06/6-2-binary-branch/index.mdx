## 🧠 The if Statement

The `if` statement executes a block of code **only when the condition is true**:

```csharp
if (condition) {
    // This code runs ONLY if condition is true
}
```

<div class="architect-rule">

#### 🏗️ Architect's Rule: K&R Brace Style

In this course, we use **K&R style** (also called "Egyptian braces") — the opening brace goes on the **same line** as the statement. This is the industry standard for many teams and keeps code compact.

```csharp
// ✅ K&R Style (our standard)
if (score >= 70) {
    Console.WriteLine("Passing!");
}

// ❌ Allman Style (NOT our standard)
if (score >= 70)
{
    Console.WriteLine("Passing!");
}
```

</div>

## 🔀 The if/else Fork

When you need your program to do **one thing or another**, use `if/else`:

```csharp
int score = 85;

if (score >= 70) {
    Console.WriteLine("You passed! ✅");
} else {
    Console.WriteLine("Keep practicing. ❌");
}
```

Think of it as a **fork in the road**: the program MUST take one path or the other. It can never take both.

```
         ┌──────────────┐
         │ score >= 70?  │
         └──────┬───────┘
          YES ↙     ↘ NO
    ┌──────────┐   ┌──────────┐
    │ "Passed!" │   │ "Keep    │
    │           │   │ trying!" │
    └──────────┘   └──────────┘
          ↘          ↙
       ┌────────────────┐
       │  Continue...   │
       └────────────────┘
```

## 🎯 The Code Block: Braces Matter

Everything between `{` and `}` is a **code block**. Only the code inside the matching block executes:

```csharp
if (temperature > 100) {
    // ALL of these lines run together (or none of them)
    Console.WriteLine("WARNING: Overheating!");
    Console.WriteLine("Shutting down systems...");
    Console.WriteLine("Emergency cooling activated.");
}
// This line ALWAYS runs, regardless of temperature
Console.WriteLine("System check complete.");
```

<div class="architect-rule">

#### ⚠️ Common Bug: Missing Braces

Without braces, only the **first line** after `if` is conditional. The rest always runs. **Always use braces**, even for single-line blocks.

```csharp
// ❌ DANGEROUS — only the first line is conditional!
if (isAdmin)
    Console.WriteLine("Welcome, Admin.");
    Console.WriteLine("Loading admin panel...");  // ALWAYS runs!

// ✅ SAFE — both lines are inside the block
if (isAdmin) {
    Console.WriteLine("Welcome, Admin.");
    Console.WriteLine("Loading admin panel...");
}
```

</div>

Variables declared inside an `if` block only exist within that block (**scope**):

## 🔍 Checking Multiple Things in Sequence

You can have multiple independent `if` statements. Each one is checked separately:

```csharp
int score = 85;

// These are INDEPENDENT checks — each runs on its own
if (score >= 70) {
    Console.WriteLine("✅ Passing grade");
}

if (score >= 90) {
    Console.WriteLine("🌟 Honor roll!");
}

if (score == 100) {
    Console.WriteLine("🏆 Perfect score!");
}
```

With a score of 85, only the first message prints. With 95, the first two print. With 100, all three print. Each `if` is a separate decision.
