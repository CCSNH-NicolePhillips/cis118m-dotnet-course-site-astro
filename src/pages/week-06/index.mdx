## 🧠 The Decision Engine

Every `if` statement is a **gate** — it evaluates a condition and opens or closes the path:

```
┌─────────────────────────────────────────────────────────┐
│                  DECISION ENGINE                        │
├─────────────────────────────────────────────────────────┤
│                                                         │
│   Input: score = 85                                     │
│                                                         │
│          ┌──────────────┐                               │
│          │ score >= 90?  │                               │
│          └──────┬───────┘                               │
│           NO ↙     ↘ YES                                │
│          ┌──────────────┐                               │
│          │ score >= 80?  │     → "Grade: A"             │
│          └──────┬───────┘                               │
│           NO ↙     ↘ YES                                │
│                        → "Grade: B" ✓                   │
│          → "Grade: C or below"                          │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

The computer evaluates each condition **top to bottom** and takes the **first path that evaluates to true**.

  <div class="component-card">

  <div class="component-card">
    <h5>🔀 if / else</h5>
