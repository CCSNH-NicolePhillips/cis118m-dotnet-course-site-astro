## 🧠 What Is a Boolean?

A `bool` (short for **Boolean**, named after mathematician George Boole) is a data type that can hold exactly **two possible values**:

```csharp
bool isOnline = true;
bool isMaintenance = false;
```

That's it. No maybes, no "kind of." A boolean is an absolute binary state — the digital equivalent of flipping a switch.

## ⚖️ Comparison Operators: Asking Questions

Comparison operators compare two values and produce a `bool` result. They're the questions your program asks to make decisions:

    <tbody>
      <tr>
        <td><code>==</code></td>
        <td>Equal to</td>

<div class="architect-rule">

#### ⚠️ Architect's Warning: = vs ==

A single `=` is **assignment** (storing a value). A double `==` is **comparison** (asking a question). Mixing them up is one of the most common bugs in programming.

```csharp
int x = 5;           // Assignment: x now holds 5
bool result = x == 5; // Comparison: is x equal to 5? (true)
```

</div>

## 🔍 Storing Booleans in Variables

You can store comparison results in `bool` variables and use them later. This makes your code more readable:

```csharp
int temperature = 95;
int MAX_SAFE_TEMP = 100;
int MIN_SAFE_TEMP = 32;

// Store conditions in named booleans
bool isTooHot = temperature > MAX_SAFE_TEMP;
bool isTooFreezing = temperature < MIN_SAFE_TEMP;
bool isInSafeRange = temperature >= MIN_SAFE_TEMP && temperature <= MAX_SAFE_TEMP;

Console.WriteLine($"Temperature: {temperature}°F");
Console.WriteLine($"Too hot? {isTooHot}");
Console.WriteLine($"Freezing? {isTooFreezing}");
Console.WriteLine($"Safe range? {isInSafeRange}");
```

<div class="pro-tip">
  <h4>💡 Pro Tip: Name Your Booleans Well</h4>
  <p>Boolean variables should read like questions: <code>isActive</code>, <code>hasPermission</code>, <code>canProceed</code>. If you see <code>bool x = true;</code> in production code, that's a code smell.</p>
</div>

## 🔬 Try It: String Comparisons

Comparisons work with strings too, but be careful — string comparison is **case-sensitive** by default:

<TryItNowRunner 
  starterId="week-06-lesson-1" 
  height={380}
  code={`using System;

class Program
{
    static void Main()
    {
        string password = "OpenSesame";
        string attempt = "opensesame";
        
        // Case-sensitive comparison (default)
        bool exactMatch = password == attempt;
        Console.WriteLine($"Exact match: {exactMatch}");  // false!
        
        // Case-insensitive comparison
        bool caseInsensitive = password.ToLower() == attempt.ToLower();
        Console.WriteLine($"Case-insensitive match: {caseInsensitive}");  // true
        
        // String equality is about content, not identity
        string a = "Hello";
        string b = "Hello";
        Console.WriteLine($"a == b: {a == b}");  // true (same content)
        
        // Not equal
        Console.WriteLine($"a != b: {a != b}");  // false
    }
}`}
  instructions="Notice how 'OpenSesame' and 'opensesame' are NOT equal with ==. Use .ToLower() to compare case-insensitively!" 
/>
