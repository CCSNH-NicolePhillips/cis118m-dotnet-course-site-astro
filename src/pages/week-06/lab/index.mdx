# Lab 06: The Security Gatekeeper

<DueDateBanner week={6} type="Lab" />

**Time: 45 minutes**  
**Points: 100**

## 🎯 Mission Objective

You are building a **security access control system** for a classified facility. The system evaluates two inputs — a **Security Level** (integer) and a **Password** (string) — and grants or denies access based on decision logic. You'll use `if`, `else if`, `else`, comparison operators, logical operators (`&&`), and string comparison to implement the gatekeeper.

---

## 📋 The Problem

The facility has three access tiers:

<img src="/media/week%206/lab/ascii.jpeg" alt="Security Access Control System diagram" style="max-width: 100%; border-radius: 8px; margin: 1rem 0;" />

The user enters a **security level** (integer) and a **password** (string). Your program must check **both** values to determine the correct access tier.

---

Your program must:

        <td>Print <code>SUPERUSER ACCESS GRANTED</code> and superuser-appropriate messages</td>
      </tr>
      <tr>
        <td><strong>Invalid credentials</strong></td>
        <td>Print <code>ACCESS DENIED</code> for wrong level, wrong password, or both</td>

## 📤 Example Output

**Successful Guest Login:**
```
=== SECURITY GATEKEEPER ===
Enter Security Level (1-3): 1
Enter Password: guest123

GUEST ACCESS GRANTED
Welcome, Guest. You may view public documents.
Access expires in 30 minutes.
============================
```

**Successful Admin Login:**
```
=== SECURITY GATEKEEPER ===
Enter Security Level (1-3): 2
Enter Password: admin456

ADMIN ACCESS GRANTED
Welcome, Administrator. Full system access enabled.
You may modify records and manage users.
============================
```

**Successful Superuser Login:**
```
=== SECURITY GATEKEEPER ===
Enter Security Level (1-3): 3
Enter Password: superSecret

SUPERUSER ACCESS GRANTED
Welcome, Superuser. All restrictions lifted.
Database access, audit logs, and system config unlocked.
============================
```

**Failed Login:**
```
=== SECURITY GATEKEEPER ===
Enter Security Level (1-3): 2
Enter Password: wrongpass

ACCESS DENIED
Invalid credentials. This attempt has been logged.
============================
```
