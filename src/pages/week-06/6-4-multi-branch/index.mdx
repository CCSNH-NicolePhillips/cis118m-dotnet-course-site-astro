## 🔗 The else if Chain

When you have more than two possible outcomes, chain multiple conditions together:

```csharp
int score = 85;

if (score >= 90) {
    Console.WriteLine("Grade: A");
} else if (score >= 80) {
    Console.WriteLine("Grade: B");
} else if (score >= 70) {
    Console.WriteLine("Grade: C");
} else if (score >= 60) {
    Console.WriteLine("Grade: D");
} else {
    Console.WriteLine("Grade: F");
}
```

### How the Chain Works

```
  score = 85

  Is score >= 90? → NO (85 < 90)  ──→ skip
  Is score >= 80? → YES (85 ≥ 80) ──→ ✅ "Grade: B"
  Is score >= 70? → NEVER CHECKED (already matched)
  Is score >= 60? → NEVER CHECKED
  else            → NEVER CHECKED
```

**Critical rule**: The chain stops at the **first true condition**. Order matters!

---

## ⚠️ Order Matters: A Common Trap

If you check the **least restrictive** condition first, it catches everything:

```csharp
int score = 95;

// ❌ WRONG ORDER — score >= 60 catches everything above 60!
if (score >= 60) {
    Console.WriteLine("Grade: D");  // A 95 gets "D"!?
} else if (score >= 70) {
    Console.WriteLine("Grade: C");  // Never reached
} else if (score >= 80) {
    Console.WriteLine("Grade: B");  // Never reached
} else if (score >= 90) {
    Console.WriteLine("Grade: A");  // Never reached
}
```

<div class="architect-rule">
  <h4>🏗️ Architect's Rule: Most Restrictive First</h4>
  <p>Always order <code>else if</code> chains from <strong>most restrictive to least restrictive</strong>. Check for 90+ before 80+, 80+ before 70+, and so on. The first <code>true</code> condition wins — everything below is dead code if you get the order wrong.</p>
</div>

## 🚫 Avoiding Nesting Hell

Beginners often nest `if` statements deep. This creates hard-to-read "arrow code":

```csharp
// ❌ NESTING HELL — hard to read and maintain
if (age >= 18) {
    if (hasID) {
        if (!isExpired) {
            Console.WriteLine("Entry granted.");
        } else {
            Console.WriteLine("ID is expired.");
        }
    } else {
        Console.WriteLine("No ID.");
    }
} else {
    Console.WriteLine("Too young.");
}
```

Flatten with logical operators and early returns:

```csharp
// ✅ FLAT AND CLEAR — same logic, much easier to read
if (age < 18) {
    Console.WriteLine("Too young.");
} else if (!hasID) {
    Console.WriteLine("No ID.");
} else if (isExpired) {
    Console.WriteLine("ID is expired.");
} else {
    Console.WriteLine("Entry granted.");
}
```

## 🔍 When to Use What

| Situation | Use |
|-----------|-----|
| Yes or no decision | `if` / `if-else` |
| Multiple exclusive outcomes | `else if` chain |
| Multiple independent checks | Separate `if` statements |
| Complex combined conditions | `&&`, `\|\|`, `!` |
