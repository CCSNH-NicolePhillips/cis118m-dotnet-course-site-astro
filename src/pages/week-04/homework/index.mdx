## 📝 Homework 04: The Immutability Patch

Now that you understand how strings work in memory, it's time to demonstrate your knowledge of why immutability matters and when to use StringBuilder.

---

## 🧠 The Critical Questions

Answer BOTH questions in **3-5 sentences each**:

### Question 1: The Memory Problem

A junior developer writes this code to build a report with 1,000 lines:

```csharp
string report = "";
for (int i = 0; i < 1000; i++)
{
    report += $"Line {i}: Data processing complete\n";
}
```

**Explain:**
1. Why is this code inefficient from a memory perspective?
2. How many string objects are created during the loop?
3. What happens to the old strings after each iteration?

### Question 2: The Solution

**Explain:**
1. How would you rewrite the above code using StringBuilder?
2. Why is StringBuilder more efficient for this use case?
3. When should you use regular string concatenation vs. StringBuilder?
