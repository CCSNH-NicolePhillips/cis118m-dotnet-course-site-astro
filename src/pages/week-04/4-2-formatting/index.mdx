## 💉 String Interpolation: The `$` Operator

**String Interpolation** is the modern, readable way to inject variables into strings. Prefix your string with `$` and wrap variables in `{curly braces}`.

<div class="syntax-card">
  <h3>📐 Syntax Pattern</h3>
  <pre><code>$"Static text {'{'}variable{'}'} more text {'{'}anotherVariable{'}'}"</code></pre>
</div>

### Before & After: Old Way vs. Modern Way

## 🎯 Try It: Interpolation Basics

<TryItNowRunner 
  starterId="week-04-interpolation-basics" 
  height={340}
  code={`using System;

class Program
{
    static void Main()
    {
        string product = "Keyboard";
        double price = 49.99;
        int quantity = 3;
        
        // Interpolation: inject variables with braces
        Console.WriteLine($"Product: ${"{"+"product"+"}"}");
        Console.WriteLine($"Price: $${"{"+"price"+"}"}");
        Console.WriteLine($"Quantity: ${"{"+"quantity"+"}"}");
        
        // You can even do math inside the braces!
        Console.WriteLine($"Total: $${"{"+"price * quantity"+"}"}");
    }
}`}
  instructions="Run this code. Notice how braces get replaced with the actual value. Try adding another variable!"

## 🔢 Format Specifiers: Controlling Output

Inside the braces, you can add **format specifiers** to control how values are displayed:

### Common Format Specifiers

| Specifier | Meaning | Example Input | Output |
|-----------|---------|---------------|--------|
| `:C` | Currency | `price` = 49.99 | $49.99 |
| `:N2` | Number with 2 decimals | `value` = 1234.5678 | 1,234.57 |
| `:P` | Percentage | `rate` = 0.85 | 85.00% |
| `:D4` | Padded digits | `id` = 42 | 0042 |
| `,10` | Right-align (10 chars) | `name` = "Alice" | "     Alice" |
| `,-10` | Left-align (10 chars) | `name` = "Alice" | "Alice     " |

<TryItNowRunner 
  starterId="week-04-format-specifiers" 
  height={380}
  code={`using System;

class Program
{
    static void Main()
    {
        double price = 49.99;
        double rate = 0.0825; // 8.25% tax
        int orderId = 42;
        
        Console.WriteLine("=== Format Specifiers Demo ===\\n");
        
        // Currency formatting
        Console.WriteLine($"Price: ${"{"+"price:C"+"}"}");
        
        // Percentage
        Console.WriteLine($"Tax Rate: ${"{"+"rate:P"+"}"}");
        
        // Padded order ID
        Console.WriteLine($"Order ID: ${"{"+"orderId:D6"+"}"}");
        
        // Number with commas
        double bigNumber = 1234567.891;
        Console.WriteLine($"Big Number: ${"{"+"bigNumber:N2"+"}"}");
        
        // Alignment for tables
        Console.WriteLine("\\nItem            Price");
        Console.WriteLine("Keyboard        $49.99");
        Console.WriteLine("Mouse           $29.99");
    }
}`}
  instructions="Experiment with format specifiers. Try changing :C to :N2, or adjust the alignment numbers." 
/>

## 🎯 Try It: Escape Sequences

<TryItNowRunner 
  starterId="week-04-escape-sequences" 
  height={400}
  code={`using System;

class Program
{
    static void Main()
    {
        // \\n = newline
        Console.WriteLine("Line 1\\nLine 2\\nLine 3");
        
        // \\t = tab (great for alignment)
        Console.WriteLine("\\nName\\tAge\\tCity");
        Console.WriteLine("Alice\\t25\\tBoston");
        Console.WriteLine("Bob\\t30\\tSeattle");
        
        // \\\\ = literal backslash (for file paths)
        Console.WriteLine("\\nFile path: C:\\\\Users\\\\Documents\\\\file.txt");
        
        // \\" = quote inside a string
        Console.WriteLine("\\nShe said, \\"Hello, World!\\"");
        
        // Combining with interpolation
        string name = "Engineer";
        Console.WriteLine($"\\n\\tWelcome, {name}!\\n\\tSystem ready.");
    }
}`}
  instructions="Run this to see how escape sequences control output formatting. Try adding your own newlines and tabs!"

## 📝 Verbatim Strings: The `@` Prefix

Tired of escaping every backslash? Use **verbatim strings** with the `@` prefix—backslashes are treated literally:

<DeepDiveTabs
  title="Regular vs. Verbatim Strings"
  tabs={[
    {
      id: "regular",
      label: "Regular String",
      content: `
        <h3>Regular String (Escape Required)</h3>
        <pre><code>// Must escape every backslash
string path = "C:\\\\Users\\\\Documents\\\\file.txt";
string multiline = "Line 1\\nLine 2\\nLine 3";</code></pre>
        <p>Backslash is an escape character, so you need \\\\ for a literal \\.</p>
      `
    },
    {
      id: "verbatim",
      label: "@ Verbatim String",
      content: `
        <h3>Verbatim String (Literal Backslash)</h3>
        <pre><code>// @ makes backslash literal
string path = @"C:\\Users\\Documents\\file.txt";

// Also allows real multi-line strings!
string multiline = @"Line 1
Line 2
Line 3";</code></pre>
        <p>Perfect for file paths and multi-line text!</p>
      `
    },
    {
      id: "combined",
      label: "$@ Combined",
      content: `
        <h3>Combining Interpolation + Verbatim</h3>
        <pre><code>string user = "Alice";

// $@ enables both features!
string message = $@"Welcome, {user}!
Your files are at: C:\\Users\\{user}\\Documents";</code></pre>
        <p><strong>Order matters:</strong> Use <code>$@</code> (not @$) for interpolated verbatim strings.</p>
      `
    }
  ]}
/>

<TryItNowRunner 
  starterId="week-04-verbatim-strings" 
  height={340}
  code={`using System;

class Program
{
    static void Main()
    {
        // Verbatim string for file path
        string path = @"C:\\Users\\Student\\Documents\\project.cs";
        Console.WriteLine($"File: {path}");
        
        // Multi-line verbatim string
        string ascii = @"
   /\\_/\\  
  ( o.o ) 
   > ^ <
  /|   |\\
 (_|   |_)";
        
        Console.WriteLine(ascii);
        
        // Combined $@ for interpolated multi-line
        string user = "Engineer";
        string report = $@"
=============================
  System Report for {user}
=============================
  Status: ONLINE
  Time: {DateTime.Now}
=============================";
        
        Console.WriteLine(report);
    }
}`}
  instructions="Verbatim strings make file paths and ASCII art much easier! Try modifying the cat or adding your own ASCII design."
