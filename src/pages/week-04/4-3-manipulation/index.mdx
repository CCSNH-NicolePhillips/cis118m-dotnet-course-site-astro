## 🔍 IndexOf(): Finding the Position

`IndexOf()` returns the **zero-based position** where a substring first appears. If not found, it returns **-1**.

<TryItNowRunner 
  starterId="week-04-indexof" 
  height={380}
  code={`using System;

class Program
{
    static void Main()
    {
        string data = "Error: File not found at C:\\\\logs\\\\app.log";
        
        // Find position of specific text
        int errorPos = data.IndexOf("Error");
        int filePos = data.IndexOf("File");
        int notFoundPos = data.IndexOf("Success"); // Won't find it!
        
        Console.WriteLine($"Original: {data}");
        Console.WriteLine($"\\n'Error' found at index: {errorPos}");
        Console.WriteLine($"'File' found at index: {filePos}");
        Console.WriteLine($"'Success' found at index: {notFoundPos}");
        
        // Using IndexOf to check if something exists
        if (data.IndexOf("Error") != -1)
        {
            Console.WriteLine("\\n⚠️ This is an error message!");
        }
    }
}`}
  instructions="Run this to see how IndexOf returns positions. Notice that 'Success' returns -1 because it doesn't exist in the string."

## ✂️ Substring(): Extracting Portions

`Substring()` cuts out a portion of the string. It has two forms:
- `Substring(startIndex)` — from position to end
- `Substring(startIndex, length)` — extract specific length

        <pre><code>string text = "Hello, World!";

// Result: "World!"</code></pre>
        <p><strong>Starts at index 7</strong>, takes everything to the end.</p>

string hello = text.Substring(0, 5);
// Result: "Hello"</code></pre>
        <p><strong>Start at 0</strong>, take <strong>5 characters</strong>.</p>

<TryItNowRunner 
  starterId="week-04-substring" 
  height={420}
  code={`using System;

class Program
{
    static void Main()
    {
        string logEntry = "[2026-02-08 14:30:15] ERROR: Database connection failed";
        
        Console.WriteLine($"Full log: {logEntry}");
        Console.WriteLine();
        
        // Extract the timestamp (positions 1-19)
        string timestamp = logEntry.Substring(1, 19);
        Console.WriteLine($"Timestamp: {timestamp}");
        
        // Extract the log level using IndexOf
        int bracketEnd = logEntry.IndexOf("]");
        int colonPos = logEntry.IndexOf(":", bracketEnd);
        string level = logEntry.Substring(bracketEnd + 2, colonPos - bracketEnd - 2);
        Console.WriteLine($"Level: {level}");
        
        // Extract the message (everything after the colon)
        string message = logEntry.Substring(colonPos + 2);
        Console.WriteLine($"Message: {message}");
        
        // Parse an email
        string email = "engineer@techcorp.io";
        int atIndex = email.IndexOf("@");
        string username = email.Substring(0, atIndex);
        string domain = email.Substring(atIndex + 1);
        Console.WriteLine($"\\nEmail: {email}");
        Console.WriteLine($"Username: {username}");
        Console.WriteLine($"Domain: {domain}");
    }
}`}
  instructions="Study how IndexOf and Substring work together to parse structured data. Try parsing different parts of the log entry!"

## 🔄 Replace(): Swapping Content

`Replace()` finds all occurrences of a substring and swaps them with a new value. Remember: it returns a **NEW string** (immutability!).

<TryItNowRunner 
  starterId="week-04-replace" 
  height={380}
  code={`using System;

class Program
{
    static void Main()
    {
        string template = "Hello, {NAME}! Welcome to {COMPANY}.";
        
        // Replace placeholders with actual values
        string personalized = template
            .Replace("{NAME}", "Sarah")
            .Replace("{COMPANY}", "TechCorp");
        
        Console.WriteLine($"Template: {template}");
        Console.WriteLine($"Result:   {personalized}");
        
        // Sanitize user input
        string userInput = "   Hello   World   ";
        string cleaned = userInput
            .Replace("   ", " ")  // Multiple spaces to single
            .Trim();               // Remove leading/trailing
        
        Console.WriteLine($"\\nRaw input:   \\"{userInput}\\"");
        Console.WriteLine($"Cleaned:     \\"{cleaned}\\"");
        
        // Replace characters
        string phone = "(555) 123-4567";
        string digitsOnly = phone
            .Replace("(", "")
            .Replace(")", "")
            .Replace(" ", "")
            .Replace("-", "");
        
        Console.WriteLine($"\\nPhone: {phone}");
        Console.WriteLine($"Digits: {digitsOnly}");
    }
}`}
  instructions="Replace is powerful for templates and data cleaning. Try chaining multiple Replace calls together!" 
/>

## 💥 Split(): Breaking Into Arrays

`Split()` is your most powerful parsing tool—it breaks a string into an **array of substrings** based on a delimiter.

<div class="split-diagram">
  <div class="split-before">
    <code>"apple,banana,cherry"</code>
  </div>
  <div class="split-arrow">
    <span>.Split(',')</span>
    <span class="arrow">↓</span>
  </div>
  <div class="split-after">
    <div class="array-box">
      <div class="array-item"><span class="index">[0]</span> "apple"</div>
      <div class="array-item"><span class="index">[1]</span> "banana"</div>
      <div class="array-item"><span class="index">[2]</span> "cherry"</div>
    </div>
  </div>
</div>

<TryItNowRunner 
  starterId="week-04-split-basic" 
  height={380}
  code={`using System;

class Program
{
    static void Main()
    {
        // Split by comma
        string fruits = "apple,banana,cherry,date";
        string[] fruitArray = fruits.Split(',');
        
        Console.WriteLine("=== Fruits ===");
        for (int i = 0; i < fruitArray.Length; i++)
        {
            Console.WriteLine($"[{i}] {fruitArray[i]}");
        }
        
        // Split by multiple delimiters
        string data = "red;green|blue,yellow";
        string[] colors = data.Split(new char[] { ';', '|', ',' });
        
        Console.WriteLine("\\n=== Colors ===");
        foreach (string color in colors)
        {
            Console.WriteLine($"- {color}");
        }
        
        // Split a sentence into words
        string sentence = "The quick brown fox jumps";
        string[] words = sentence.Split(' ');
        
        Console.WriteLine($"\\nWord count: {words.Length}");
    }
}`}
  instructions="Split turns a single string into an array you can loop through. This is essential for CSV parsing!" 
/>

## 📊 Real-World Example: Parsing CSV Data

CSV (Comma-Separated Values) is everywhere—exports from Excel, database dumps, API responses. Let's parse it:

<TryItNowRunner 
  starterId="week-04-csv-parsing" 
  height={500}
  code={`using System;

class Program
{
    static void Main()
    {
        // Simulated CSV data (like from a file)
        string csvData = @"Name,Age,City
Alice,28,Boston
Bob,35,Seattle
Charlie,22,Austin
Diana,31,Denver";
        
        Console.WriteLine("=== RAW CSV DATA ===");
        Console.WriteLine(csvData);
        Console.WriteLine();
        
        // Split into rows
        string[] rows = csvData.Split('\\n');
        
        // First row is the header
        string[] headers = rows[0].Split(',');
        
        Console.WriteLine("=== PARSED DATA ===");
        Console.WriteLine($"{"Name",-12} {"Age",5} {"City",-10}");
        Console.WriteLine(new string('-', 30));
        
        // Process data rows (skip header at index 0)
        for (int i = 1; i < rows.Length; i++)
        {
            string[] columns = rows[i].Split(',');
            
            string name = columns[0];
            string age = columns[1];
            string city = columns[2];
            
            Console.WriteLine($"{name,-12} {age,5} {city,-10}");
        }
        
        Console.WriteLine("\\n=== SUMMARY ===");
        Console.WriteLine($"Total records: {rows.Length - 1}");
    }
}`}
  instructions="This is exactly how you'll parse CSV data in Lab 04! Notice the pattern: Split rows first, then Split each row into columns." 
/>

## 🧹 Helper Methods: Contains, Trim, ToUpper/ToLower

<div class="helper-methods">
  <div class="helper-card">
    <h4>❓ Contains()</h4>
    <p>Returns <code>true</code> if substring exists</p>
    <pre><code>"Hello World".Contains("World") // true</code></pre>
  </div>
  <div class="helper-card">
    <h4>🧹 Trim()</h4>
    <p>Removes leading/trailing whitespace</p>
    <pre><code>"  Hello  ".Trim() // "Hello"</code></pre>
  </div>
  <div class="helper-card">
    <h4>⬆️ ToUpper()</h4>
    <p>Converts to UPPERCASE</p>
    <pre><code>"Hello".ToUpper() // "HELLO"</code></pre>
  </div>
  <div class="helper-card">
    <h4>⬇️ ToLower()</h4>
    <p>Converts to lowercase</p>
    <pre><code>"Hello".ToLower() // "hello"</code></pre>
  </div>
</div>

<TryItNowRunner 
  starterId="week-04-helper-methods" 
  height={360}
  code={`using System;

class Program
{
    static void Main()
    {
        string input = "   Hello, WORLD!   ";
        
        Console.WriteLine($"Original:  \\"{input}\\"");
        Console.WriteLine($"Trimmed:   \\"{input.Trim()}\\"");
        Console.WriteLine($"Upper:     \\"{input.Trim().ToUpper()}\\"");
        Console.WriteLine($"Lower:     \\"{input.Trim().ToLower()}\\"");
        
        // Case-insensitive search
        string search = "world";
        bool found = input.ToLower().Contains(search.ToLower());
        Console.WriteLine($"\\nContains '{search}' (case-insensitive): {found}");
        
        // Chaining methods
        string messy = "   USER@EMAIL.COM   ";
        string clean = messy.Trim().ToLower();
        Console.WriteLine($"\\nCleaned email: {clean}");
    }
}`}
  instructions="Helper methods make data cleaning easy. Notice how you can chain them together!"
