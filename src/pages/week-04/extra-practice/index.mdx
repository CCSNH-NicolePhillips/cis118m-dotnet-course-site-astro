## 🔬 Drill 1: Email Parser

Extract the username and domain from an email address using `IndexOf()` and `Substring()`.

<TryItNowRunner 
  starterId="week-04-drill-email" 
  height={320}
  code={`using System;

class Program
{
    static void Main()
    {
        string email = "student@university.edu";
        
        // TODO: Find the @ symbol position
        // int atIndex = ...
        
        // TODO: Extract the username (before @)
        // string username = ...
        
        // TODO: Extract the domain (after @)
        // string domain = ...
        
        Console.WriteLine($"Email: {email}");
        // Console.WriteLine($"Username: {username}");
        // Console.WriteLine($"Domain: {domain}");
    }
}`}
  instructions="Use IndexOf('@') to find the position, then Substring() to extract each part." 
/>

<details>
  <summary>💡 Solution</summary>

```csharp
int atIndex = email.IndexOf('@');
string username = email.Substring(0, atIndex);
string domain = email.Substring(atIndex + 1);
```

</details>

## 📚 Practice Tips

<div class="tips-grid">
  <div class="tip">
    <h4>🔗 Chain Methods</h4>
    <p>String methods can be chained: <code>text.Trim().ToLower().Replace(" ", "_")</code></p>

  <div class="tip">
    <h4>🔍 Use IndexOf First</h4>
    <p>Before using Substring, always find the position with IndexOf</p>

  </div>
  <div class="tip">
    <h4>🏗️ StringBuilder in Loops</h4>
    <p>Always use StringBuilder when building strings inside loops</p>
