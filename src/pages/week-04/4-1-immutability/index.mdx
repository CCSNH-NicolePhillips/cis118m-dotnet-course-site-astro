## 🧠 What Is Immutability?

**Immutable** means "cannot be changed." When you create a string in C#, it is permanently fixed in memory. Any operation that appears to modify a string actually creates a **brand new string** in a different memory location.

## 🏗️ Memory Architecture: Stack vs. Heap

Strings are **reference types** stored on the **Heap**, with a pointer on the **Stack**:

<div class="memory-diagram">
  <div class="memory-section stack">
    <h4>📦 Stack (Fast, Small)</h4>
    <div class="memory-block">
      <code>name</code> → <span class="pointer">0x7FFA2B10</span>
    </div>
    <p class="memory-note">Holds the <strong>reference</strong> (address) to the actual string</p>
  </div>
  <div class="memory-arrow">→</div>
  <div class="memory-section heap">
    <h4>🗄️ Heap (Large, Managed)</h4>
    <div class="memory-block heap-block">
      <span class="address">0x7FFA2B10:</span>
      <code>"Alice"</code>
    </div>
    <p class="memory-note">Holds the <strong>actual character data</strong></p>
  </div>
</div>

## 🔬 Proof: Strings Create New Objects

Let's prove that "modifying" a string creates a new object. We'll use `Object.ReferenceEquals()` to check if two variables point to the same memory location:

<TryItNowRunner 
  starterId="week-04-immutability-proof" 
  height={380}
  code={`using System;

class Program
{
    static void Main()
    {
        string original = "Hello";
        string modified = original;  // Same reference!
        
        Console.WriteLine("=== Before Modification ===");
        Console.WriteLine($"original: {original}");
        Console.WriteLine($"modified: {modified}");
        Console.WriteLine($"Same object? {Object.ReferenceEquals(original, modified)}");
        
        // Now "modify" the string
        modified = modified + " World";
        
        Console.WriteLine("\\n=== After Modification ===");
        Console.WriteLine($"original: {original}");
        Console.WriteLine($"modified: {modified}");
        Console.WriteLine($"Same object? {Object.ReferenceEquals(original, modified)}");
    }
}`}
  instructions="Run this code and observe: after concatenation, 'original' and 'modified' point to DIFFERENT memory locations. The original string was never changed!" 
/>

## 💀 The Hidden Cost: Memory Pressure

Every string operation creates garbage. In a loop, this becomes **catastrophic**:

<TryItNowRunner 
  starterId="week-04-memory-pressure" 
  height={340}
  code={`using System;

class Program
{
    static void Main()
    {
        string result = "";
        
        // Each iteration creates a NEW string!
        for (int i = 1; i <= 5; i++)
        {
            result = result + i + " ";
            Console.WriteLine($"Iteration {i}: result = \\"{result}\\"");
            // Behind the scenes: OLD result becomes garbage!
        }
        
        Console.WriteLine($"\\nFinal: {result}");
        Console.WriteLine("⚠️ This created 5 intermediate strings (all garbage now)!");
    }
}`}
  instructions="Watch each iteration. Every += creates a NEW string and abandons the old one. Imagine doing this 10,000 times!" 
/>

<div class="warning-box">
  <h4>⚠️ Performance Warning</h4>
  <p>Building strings in a loop with <code>+</code> or <code>+=</code> is an <strong>O(n²)</strong> operation! Each concatenation copies all previous characters. For 1,000 iterations, you'd copy approximately <strong>500,000 characters total</strong>.</p>
  <p><strong>Solution:</strong> Use <code>StringBuilder</code> (covered in Section 4.4)</p>
</div>

## 🧪 String Methods Return NEW Strings

Even methods like `ToUpper()` and `Replace()` don't modify the original—they return **new strings**:

<TryItNowRunner 
  starterId="week-04-methods-new-strings" 
  height={320}
  code={`using System;

class Program
{
    static void Main()
    {
        string greeting = "hello world";
        
        // These methods return NEW strings
        string upper = greeting.ToUpper();
        string replaced = greeting.Replace("world", "C#");
        
        Console.WriteLine($"Original:  \\"{greeting}\\"");
        Console.WriteLine($"ToUpper:   \\"{upper}\\"");
        Console.WriteLine($"Replace:   \\"{replaced}\\"");
        
        Console.WriteLine($"\\nOriginal unchanged? {greeting == "hello world"}");
    }
}`}
  instructions="Notice: the original string 'greeting' is NEVER modified. Each method returns a brand new string." 
/>

## 📋 Section Summary

<div class="summary-box">
  <h3>🔮 Key Takeaways: The Immutability Rule</h3>
  <ul>
    <li><strong>Strings are immutable:</strong> Once created, they cannot be modified</li>
    <li><strong>Stack vs. Heap:</strong> Variables hold references (Stack), actual data lives on the Heap</li>
    <li><strong>"Modification" creates new strings:</strong> Every operation returns a new object</li>
    <li><strong>Memory pressure:</strong> Loop concatenation creates O(n²) garbage</li>
    <li><strong>Methods return new strings:</strong> <code>ToUpper()</code>, <code>Replace()</code>, etc. never modify the original</li>
  </ul>
</div>
