## 🎯 Mission Objective

You've received **messy user input** that needs to be cleaned up and formatted before it can be stored in the database. Use **string methods** to sanitize the data.

---

## 📋 The Problem

A user submitted their profile information, but it's full of problems:
- Extra spaces everywhere
- Inconsistent capitalization  
- Unwanted characters in the phone number
- Needs reformatting for display

**Your job:** Clean it up using the string methods you learned this week!

## 💡 Hints

<details>
<summary>Hint 1: Trim removes whitespace</summary>

```csharp
string messy = "   hello world   ";
string clean = messy.Trim();  // "hello world"
```

</details>

<details>
<summary>Hint 2: Replace can remove characters</summary>

```csharp
string phone = "(555) 123-4567";
string clean = phone.Replace("(", "").Replace(")", "").Replace(" ", "");
// Result: "555-123-4567"
```

</details>

<details>
<summary>Hint 3: Substring extracts part of a string</summary>

```csharp
string phone = "555-123-4567";
string areaCode = phone.Substring(0, 3);  // "555"
// Substring(startIndex, length)
```

</details>

<details>
<summary>Hint 4: String interpolation</summary>

```csharp
string name = "John";
int age = 25;
Console.WriteLine($"Name: {name}, Age: {age}");
```

</details>
