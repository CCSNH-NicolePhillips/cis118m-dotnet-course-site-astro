## 🎯 Mission Objective

You've intercepted a **raw CSV data stream** from a legacy system. Your mission: parse this comma-separated data using `Split()` and transform it into a clean, formatted report using string interpolation.

This lab tests your mastery of:
- **Split()** to break strings into arrays
- **String Interpolation** for formatted output
- **Escape Sequences** for alignment
- **Trim()** and **Replace()** for data cleaning
- **StringBuilder** for efficient string building

You will parse employee records in this CSV format:

## 🔮 Why StringBuilder? The Immutability Problem

Remember from Section 4.1: **strings are immutable**. Every time you concatenate strings in a loop, you create garbage:

<div class="problem-box">
  <h4>❌ The Bad Way (Creates 1000+ strings!)</h4>

```csharp
string report = "";
for (int i = 0; i < rows.Length; i++)
{
    report += rows[i] + "\n";  // Each += creates a NEW string!
}
```

  <p>Each <code>+=</code> copies the entire existing string plus the new content into a <strong>brand new string object</strong>. With 4 employees, that's manageable. With 10,000 employees? Your program crawls.</p>
</div>

<div class="solution-box">
  <h4>✅ The Right Way (StringBuilder)</h4>

```csharp
StringBuilder sb = new StringBuilder();
for (int i = 0; i < rows.Length; i++)
{
    sb.AppendLine(rows[i]);  // Modifies the buffer in place!
}
string report = sb.ToString();
```

  <p><code>StringBuilder</code> maintains a mutable buffer. <code>Append()</code> adds to the existing buffer without creating new objects. When done, call <code>.ToString()</code> once.</p>
</div>

<TryItNowRunner 
  starterId="week-04-lab-solution" 
  height={800}
  code={`using System;
using System.Text;  // Required for StringBuilder

class Program
{
    static void Main()
    {
        // The raw CSV data stream
        string csvData = @"ID,Name,Department,Salary
E001,Alice Johnson,Engineering,85000
E002,Bob Smith,Marketing,72000
E003,Charlie Brown,Engineering,91000
E004,Diana Ross,Sales,68000";

        // Step 1: Split into rows
        string[] rows = csvData.Split('\\n');
        
        // Step 2: Create StringBuilder (efficient for building in loops!)
        StringBuilder report = new StringBuilder();
        
        // Step 3: Append header box
        report.AppendLine("╔══════════════════════════════════════════════╗");
        report.AppendLine("║         EMPLOYEE DIRECTORY REPORT            ║");
        report.AppendLine("╠══════════════════════════════════════════════╣");
        report.AppendLine($"║ {"ID",-7} {"Name",-20} {"Dept",-12} {"Pay",7} ║");
        report.AppendLine("╠══════════════════════════════════════════════╣");
        
        // Step 4: Initialize counters
        int totalEmployees = 0;
        int totalPayroll = 0;
        
        // Step 5: Loop through data rows (skip header)
        for (int i = 1; i < rows.Length; i++)
        {
            // Split each row by comma
            string[] cols = rows[i].Split(',');
            
            // Extract values
            string id = cols[0];
            string name = cols[1];
            string dept = cols[2];
            int salary = int.Parse(cols[3]);
            
            // Append formatted row to StringBuilder
            report.AppendLine($"║ {id,-7} {name,-20} {dept,-12} {salary,7:C0} ║");
            
            // Update counters
            totalEmployees++;
            totalPayroll += salary;
        }
        
        // Step 6: Append footer with totals
        report.AppendLine("╠══════════════════════════════════════════════╣");
        report.AppendLine($"║ TOTAL EMPLOYEES: {totalEmployees,-28} ║");
        report.AppendLine($"║ TOTAL PAYROLL:   {totalPayroll:C0,-28} ║");
        report.AppendLine("╚══════════════════════════════════════════════╝");
        
        // Step 7: Print the complete report (one Console.WriteLine!)
        Console.WriteLine(report.ToString());
    }
}`}
  instructions="This solution uses StringBuilder to build the entire report efficiently, then prints it once at the end." 
/>
