## 💡 Hints

<details>
<summary>Hint 1: Splitting into rows</summary>

```csharp
string[] rows = csvData.Split('\n');
// rows[0] = "ID,Name,Department,Salary" (header)
// rows[1] = "E001,Alice Johnson,Engineering,85000"
```

</details>

<details>
<summary>Hint 2: Splitting into columns</summary>

```csharp
string[] cols = rows[i].Split(',');
// cols[0] = "E001"
// cols[1] = "Alice Johnson"
// cols[2] = "Engineering"
// cols[3] = "85000"
```

</details>

<details>
<summary>Hint 3: Parsing and formatting salary</summary>

```csharp
int salary = int.Parse(cols[3]);
Console.WriteLine($"{id} - {name} ({dept}) - ${salary:N0}");
```

The `:N0` formats the number with commas (85000 → 85,000).

</details>
