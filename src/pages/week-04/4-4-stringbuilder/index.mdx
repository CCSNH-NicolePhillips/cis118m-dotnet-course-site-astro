## 🎬 The Problem: String Concatenation in Loops

Before we learn the solution, let's understand the problem:

<div class="problem-visualization">
  <h3>❌ String Concatenation: O(n²) Memory Disaster</h3>
  <div class="iteration-flow">
    <div class="iteration">
      <span class="iter-num">i=1</span>
      <code>result = "" + "1"</code>
      <span class="new-string">"1"</span>
      <span class="garbage">💀</span>
    </div>
    <div class="iteration">
      <span class="iter-num">i=2</span>
      <code>result = "1" + "2"</code>
      <span class="new-string">"12"</span>
      <span class="garbage">💀💀</span>
    </div>
    <div class="iteration">
      <span class="iter-num">i=3</span>
      <code>result = "12" + "3"</code>
      <span class="new-string">"123"</span>
      <span class="garbage">💀💀💀</span>
    </div>
    <div class="iteration">
      <span class="iter-num">i=1000</span>
      <code>result = "..." + "1000"</code>
      <span class="new-string">"1...1000"</span>
      <span class="garbage">💀×999</span>
    </div>
  </div>
  <p class="problem-note">Each iteration copies ALL previous characters into a new string. 1,000 iterations = ~500,000 character copies!</p>
</div>

## ✅ The Solution: StringBuilder

`StringBuilder` is a **mutable** character buffer. Instead of creating new strings, it expands an internal array. When done, call `.ToString()` to get the final string.

### ❌ String (Immutable)

```csharp
string result = "";
for (int i = 0; i < 1000; i++)
{
    result += i + " ";  // 💀 NEW STRING EACH TIME!
}
```
Creates 1,000 intermediate strings 😱

### ✅ StringBuilder (Mutable)

```csharp
StringBuilder sb = new StringBuilder();
for (int i = 0; i < 1000; i++)
{
    sb.Append(i).Append(" ");  // Same buffer!
}
string result = sb.ToString();
```
Creates 1 final string ✨

## 🔧 StringBuilder Basics

<div class="important-note">
  <h4>📦 Required Namespace</h4>
  <code>using System.Text;</code>
  <p>StringBuilder lives in the System.Text namespace. Add this at the top of your file!</p>
</div>

<TryItNowRunner 
  starterId="week-04-stringbuilder-basics" 
  height={420}
  code={`using System;
using System.Text;  // Required for StringBuilder!

class Program
{
    static void Main()
    {
        // Create a StringBuilder
        StringBuilder sb = new StringBuilder();
        
        // Append text (no new strings created!)
        sb.Append("Hello");
        sb.Append(", ");
        sb.Append("World!");
        
        // Convert to string when done
        string result = sb.ToString();
        Console.WriteLine(result);
        
        // You can chain Append calls
        StringBuilder report = new StringBuilder();
        report.Append("=== Report ===")
              .AppendLine()               // Adds newline
              .Append("Status: ")
              .AppendLine("Online")
              .Append("Users: ")
              .Append(42);
        
        Console.WriteLine();
        Console.WriteLine(report.ToString());
    }
}`}
  instructions="Notice: StringBuilder uses Append() instead of +. You can chain multiple Append calls. Call ToString() at the end!" 
/>

<div class="methods-grid">

<TryItNowRunner 
  starterId="week-04-stringbuilder-methods" 
  height={440}
  code={`using System;
using System.Text;

class Program
{
    static void Main()
    {
        StringBuilder sb = new StringBuilder("Hello World");
        Console.WriteLine($"Original: {sb}");
        
        // Replace in place (no new string!)
        sb.Replace("World", "C#");
        Console.WriteLine($"After Replace: {sb}");
        
        // Insert at position
        sb.Insert(0, ">>> ");
        Console.WriteLine($"After Insert: {sb}");
        
        // Append more
        sb.Append(" <<<");
        Console.WriteLine($"After Append: {sb}");
        
        // Remove characters (start index, length)
        sb.Remove(0, 4);  // Remove ">>> "
        Console.WriteLine($"After Remove: {sb}");
        
        // Check length and capacity
        Console.WriteLine($"\\nLength: {sb.Length}");
        Console.WriteLine($"Capacity: {sb.Capacity}");
        
        // Clear resets to empty
        sb.Clear();
        Console.WriteLine($"After Clear: \\"{sb}\\"");
        Console.WriteLine($"Length after Clear: {sb.Length}");
    }
}`}
  instructions="StringBuilder's methods modify the SAME buffer. No garbage created!" 
/>

## 🏎️ Performance Demonstration

Let's prove that StringBuilder is faster for building large strings:

<TryItNowRunner 
  starterId="week-04-performance-demo" 
  height={460}
  code={`using System;
using System.Text;
using System.Diagnostics;

class Program
{
    static void Main()
    {
        const int iterations = 10000;
        
        // Method 1: String concatenation (SLOW!)
        Stopwatch sw1 = Stopwatch.StartNew();
        string result1 = "";
        for (int i = 0; i < iterations; i++)
        {
            result1 += "x";
        }
        sw1.Stop();
        
        // Method 2: StringBuilder (FAST!)
        Stopwatch sw2 = Stopwatch.StartNew();
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < iterations; i++)
        {
            sb.Append("x");
        }
        string result2 = sb.ToString();
        sw2.Stop();
        
        Console.WriteLine($"Building a {iterations:N0}-character string:\\n");
        Console.WriteLine($"String concatenation: {sw1.ElapsedMilliseconds} ms");
        Console.WriteLine($"StringBuilder:        {sw2.ElapsedMilliseconds} ms");
        
        double speedup = (double)sw1.ElapsedMilliseconds / Math.Max(sw2.ElapsedMilliseconds, 1);
        Console.WriteLine($"\\nStringBuilder is ~{speedup:F0}x faster!");
        
        Console.WriteLine($"\\nBoth produce same result: {result1.Length == result2.Length}");
    }
}`}
  instructions="Watch the dramatic performance difference! StringBuilder is orders of magnitude faster for large string building." 
/>

## 📊 Real-World Example: Building a Report

<TryItNowRunner 
  starterId="week-04-report-builder" 
  height={520}
  code={`using System;
using System.Text;

class Program
{
    static void Main()
    {
        // Simulated data
        string[] names = { "Alice", "Bob", "Charlie", "Diana" };
        int[] scores = { 95, 87, 92, 78 };
        
        // Build a formatted report with StringBuilder
        StringBuilder report = new StringBuilder();
        
        // Header
        report.AppendLine("╔════════════════════════════════╗");
        report.AppendLine("║     STUDENT GRADE REPORT       ║");
        report.AppendLine("╠════════════════════════════════╣");
        
        // Column headers
        report.AppendLine($"║ {"Name",-12} {"Score",6} {"Grade",6}  ║");
        report.AppendLine("╠════════════════════════════════╣");
        
        // Data rows
        int total = 0;
        for (int i = 0; i < names.Length; i++)
        {
            string grade = scores[i] >= 90 ? "A" : 
                          scores[i] >= 80 ? "B" : 
                          scores[i] >= 70 ? "C" : "F";
            
            report.AppendLine($"║ {names[i],-12} {scores[i],6} {grade,6}  ║");
            total += scores[i];
        }
        
        // Footer
        report.AppendLine("╠════════════════════════════════╣");
        double avg = (double)total / names.Length;
        report.AppendLine($"║ {"Average:",-12} {avg,6:F1}        ║");
        report.AppendLine("╚════════════════════════════════╝");
        
        // Output the final report
        Console.WriteLine(report.ToString());
    }
}`}
  instructions="This report is built efficiently in one buffer. Imagine doing this with string concatenation—it would create dozens of intermediate strings!" 
/>

## 📋 Section Summary

<div class="summary-box">
  <h3>🏗️ Key Takeaways: StringBuilder</h3>
  <ul>
    <li><strong>Problem:</strong> String concatenation in loops creates O(n²) garbage</li>
    <li><strong>Solution:</strong> StringBuilder maintains a mutable buffer</li>
    <li><strong>Namespace:</strong> System.Text</li>
    <li><strong>Key Methods:</strong> Append(), AppendLine(), Insert(), Replace(), Remove(), Clear()</li>
    <li><strong>Finish with:</strong> .ToString() to get the final string</li>
    <li><strong>Rule:</strong> Use StringBuilder when building strings in loops</li>
  </ul>
</div>

**Standard Pattern:**

```csharp
StringBuilder sb = new StringBuilder();
foreach (var item in items)
{
    sb.AppendLine(item.ToString());
}
string result = sb.ToString();
```
