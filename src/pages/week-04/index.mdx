## 🧠 The Immutability Principle

When you "change" a string, C# doesn't modify the original—it creates a **brand new object** in memory:

```
┌─────────────────────────────────────────────────────────┐
│                    HEAP MEMORY                          │
├─────────────────────────────────────────────────────────┤
│                                                         │
│   string name = "Hello";                                │
│   ┌─────────┐                                          │
│   │ "Hello" │ ← Original object                        │
│   └─────────┘                                          │
│                                                         │
│   name = name + " World";                               │
│   ┌─────────┐     ┌───────────────┐                    │
│   │ "Hello" │     │ "Hello World" │ ← NEW object       │
│   └─────────┘     └───────────────┘                    │
│   (orphaned)       ↑ name now points here              │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

The old "Hello" string is left behind for garbage collection. This is **safe** but can be **slow** if you're building strings in a loop.

## 🎨 String Interpolation

The modern way to embed variables in text—clean, readable, and type-safe:

```csharp
string name = "Architect";
int level = 42;
decimal rate = 125.50m;

// The OLD way (concatenation) - messy
Console.WriteLine("Welcome, " + name + "! Level: " + level);

// The NEW way (interpolation) - clean
Console.WriteLine($"Welcome, {name}! Level: {level}");

// With formatting
Console.WriteLine($"Your rate: {rate:C}");  // → "Your rate: $125.50"
```

## ⚡ Performance Warning

When building strings in a loop, **use StringBuilder**:

```csharp
// ❌ BAD: Creates 1000 new string objects
string result = "";
for (int i = 0; i < 1000; i++)
{
    result += i.ToString();  // New object every iteration!
}

// ✅ GOOD: Uses a single mutable buffer
StringBuilder sb = new StringBuilder();
for (int i = 0; i < 1000; i++)
{
    sb.Append(i);  // Modifies the same buffer
}
string result = sb.ToString();
```
