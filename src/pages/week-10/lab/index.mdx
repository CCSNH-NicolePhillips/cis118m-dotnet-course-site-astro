## Mission Objective

Build a **Student Report Generator**. The program accepts information about three students from the user and prints a formatted report for each. The key requirement is architectural: **all display logic must live inside named, parameterized methods**. `Main` collects input and calls methods — it does not contain any `Console.WriteLine` formatting logic directly.

## Method Architecture

Your required method signatures — do not change these:

```csharp
static void PrintReportHeader()
static void PrintSeparator()
static void PrintStudentRecord(string name, int grade)
static void PrintReportFooter(int studentCount)
```

`Main` must call these methods. It must not contain any string-formatting or display logic beyond the input prompts.
