## Mission Objective

Refactor a linear program into a **modular utility suite**. You must demonstrate the ability to encapsulate logic within custom methods and successfully pass dynamic data into those methods via parameters.

Your program will contain **three utility methods**, each handling a specific system task. All three methods must be called from `Main` **at least twice** using different arguments to prove reusability.

## Requirements

<div class="styled-table-container">
  <table>
    <thead>
      <tr>
        <th>Requirement</th>
        <th>Details</th>
      </tr>
    </thead>
    <tbody>
      <tr>
        <td><strong>System Greeting</strong></td>
        <td>Create a <code>void</code> method that accepts a <code>string</code> parameter (user's name) and prints a formal system initialization message. Example: <code>System initialized for user: [name]</code></td>
      </tr>
      <tr>
        <td><strong>Measurement Converter</strong></td>
        <td>Create a <code>void</code> method that accepts a <code>double</code> value (distance in miles) and prints the calculated equivalent in kilometers. Conversion: <code>miles * 1.60934</code>. Format to 2 decimal places.</td>
      </tr>
      <tr>
        <td><strong>Status Monitor</strong></td>
        <td>Create a <code>void</code> method that accepts an <code>int</code> (battery percentage) and a <code>bool</code> (is charging). Use an <code>if/else</code> structure inside the method to print a specific system status report based on the values.</td>
      </tr>
      <tr>
        <td><strong>Reusability</strong></td>
        <td>All three methods must be called from <code>Main</code> <strong>at least twice</strong> using <strong>different arguments</strong> each time</td>
      </tr>
      <tr>
        <td><strong>No repeated code</strong></td>
        <td>The DRY Principle applies throughout. No display logic may be duplicated.</td>
      </tr>
      <tr>
        <td><strong>Brace style</strong></td>
        <td>K&amp;R — opening brace on same line as the method signature and control structures</td>
      </tr>
    </tbody>
  </table>
</div>

## Method Signatures

Your required method signatures — do not change these:

```csharp
static void GreetUser(string name)
static void ConvertMilesToKm(double miles)
static void CheckBatteryStatus(int percentage, bool isCharging)
```
