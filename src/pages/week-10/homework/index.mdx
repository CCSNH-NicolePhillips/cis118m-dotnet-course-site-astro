## Reflection Prompt

<div class="component-cards">
  <div class="component-card">
    <h3>Method Design Analysis</h3>
    <p>In 3–5 sentences per question, answer the following:</p>
    <ol>
      <li>
        <strong>The Method Signature:</strong> Identify and explain each of the three elements in the signature <code>static void PrintStudentRecord(string name, int grade)</code>. What is the purpose of each element? What would change if the return type were <code>int</code> instead of <code>void</code>?
      </li>
      <li>
        <strong>Parameters vs Arguments:</strong> Explain the difference between a parameter and an argument using a specific example. Why does the order of arguments at the call site matter? What happens if you accidentally reverse two arguments of the same type?
      </li>
      <li>
        <strong>The DRY Principle:</strong> Describe the DRY Principle (Don't Repeat Yourself) and explain why repeated code is a maintenance liability — not just a style concern. Give a concrete example of a situation where a parameterized method eliminates repetition, and explain what problem that repetition would cause over time.
      </li>
    </ol>
    <p style="margin-top: 1rem; padding: 0.75rem; background: rgba(78, 201, 176, 0.1); border-radius: 8px; font-size: 0.9rem;">

    </p>
