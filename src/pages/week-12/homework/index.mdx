This reflection requires you to demonstrate <strong>analytical understanding</strong> of why classes exist, how properties control data access, and what the <code>new</code> keyword does in memory. ## Reflection Prompt

<div class="component-cards">
  <div class="component-card">
    <h3>Class Design Analysis</h3>
    <p>In 3-5 sentences per question, answer the following:</p>
    <ol>
      <li>
        <strong>The Class as a Blueprint:</strong> Explain what a class definition does versus what the <code>new</code> keyword does. Why does writing <code>class Student &#123; &#125;</code> not create any data? What happens in memory when you write <code>Student s = new Student();</code>?
      </li>
      <li>
        <strong>Properties and Access Control:</strong> Compare a <code>public</code> field (e.g., <code>public string name;</code>) with an auto-implemented property (e.g., <code>public string Name &#123; get; set; &#125;</code>). Why are properties preferred in modern C#? What role does the <code>private</code> access modifier play in protecting class data?
      </li>
      <li>
        <strong>Objects and the Dot Operator:</strong> Explain the dot operator pattern for reading and writing object properties. If you create two Student objects (<code>s1</code> and <code>s2</code>) from the same class, why does changing <code>s1.Name</code> not affect <code>s2.Name</code>? How does bundling data into objects improve code organization compared to using separate loose variables?
      </li>
    </ol>

    </p>
