## Mission Objective

Build a **Data Architect** program that defines two custom classes and creates multiple objects from each. You must demonstrate the ability to:

1. Define a class with auto-implemented properties (`{ get; set; }`)
2. Use `public` access modifiers on all properties
3. Create objects with the `new` keyword
4. Set property values using the dot operator
5. Display formatted object data using string interpolation

Your program will contain **two class definitions** and at least **five total object instances** (three Students and two Courses). All data must live inside objects — no loose variables for student names, IDs, or course titles.

## Class Definitions

Your required class definitions — do not change the property names or types:

```csharp
class Student {
    public string Name { get; set; }
    public int Id { get; set; }
    public double Gpa { get; set; }
}

class Course {
    public string Title { get; set; }
    public string Instructor { get; set; }
    public int Credits { get; set; }
}
```

---

## Display Method Signature

Your required display method for Student objects:

```csharp
static void DisplayStudent(Student s) {
    // Print all three properties of the Student using string interpolation
}
```

You may also write a `DisplayCourse(Course c)` method for Course objects, but this is optional.

---

## Object Creation Pattern

Every object must follow this pattern — create with `new`, assign properties via dot operator:

```csharp
Student s1 = new Student();
s1.Name = "Ada Lovelace";
s1.Id = 1001;
s1.Gpa = 3.9;
DisplayStudent(s1);
```

Do NOT do this:

```csharp
// WRONG — loose variables, not using a class
string name = "Ada Lovelace";
int id = 1001;
double gpa = 3.9;

// WRONG — object created but properties never set
Student s1 = new Student();
Console.WriteLine(s1.Name);  // Prints nothing useful — Name is null
```

---

## Expected Output Format

Your output should display each object clearly. The exact formatting is flexible, but every property must appear. Example:

```
--- Student Records ---
Name: Ada Lovelace | ID: 1001 | GPA: 3.9
Name: Alan Turing  | ID: 1002 | GPA: 3.7
Name: Grace Hopper | ID: 1003 | GPA: 4.0

--- Course Catalog ---
Course: Intro to C# | Instructor: Prof. Smith | Credits: 3
Course: Data Structures | Instructor: Prof. Johnson | Credits: 4
```
