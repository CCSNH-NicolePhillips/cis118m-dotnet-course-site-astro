## The new Keyword: Creating an Object

The `new` keyword constructs an object from a class blueprint. It allocates memory for the object's properties and returns a reference to that memory:

```csharp
Student ada = new Student();
```

This line does three things:
1. **Allocates memory** for a new Student object with space for Name, Id, and Gpa
2. **Initializes properties** to their default values (`null` for strings, `0` for numbers)
3. **Returns a reference** — `ada` now points to the newly created Student object

## The Dot Operator: Accessing Object State

Once you have an object, the **dot operator** (`.`) lets you read and write its properties:

```csharp
Student ada = new Student();

// WRITE: assign values to properties
ada.Name = "Ada Lovelace";
ada.Id = 1001;
ada.Gpa = 3.9;

// READ: access property values
Console.WriteLine(ada.Name);   // Output: Ada Lovelace
Console.WriteLine(ada.Id);     // Output: 1001
Console.WriteLine(ada.Gpa);    // Output: 3.9
```

The dot operator follows the pattern: `objectVariable.PropertyName`. On the left side of `=`, it writes a value. On the right side (or in an expression), it reads the value.

<div class="architect-rule">

### Architect's Rule: The Dot Operator Is the Access Gateway

Every interaction with an object goes through the dot operator. Reading data: `student.Name`. Writing data: `student.Name = "Ada"`. Calling methods: `account.Deposit(100)`. The dot operator is the single point of access — the object's public interface. If a property is `private`, the dot operator from outside the class will not reach it. The access modifier controls what the dot operator can access.

</div>

## Multiple Instances: Independent Objects from One Blueprint

The power of classes emerges when you create **multiple objects** from the same blueprint. Each object carries its own independent copy of the data:

```csharp
Student student1 = new Student();
student1.Name = "Ada Lovelace";
student1.Id = 1001;
student1.Gpa = 3.9;

Student student2 = new Student();
student2.Name = "Alan Turing";
student2.Id = 1002;
student2.Gpa = 3.7;

Student student3 = new Student();
student3.Name = "Grace Hopper";
student3.Id = 1003;
student3.Gpa = 4.0;

Console.WriteLine($"{student1.Name}: {student1.Gpa}");  // Ada Lovelace: 3.9
Console.WriteLine($"{student2.Name}: {student2.Gpa}");  // Alan Turing: 3.7
Console.WriteLine($"{student3.Name}: {student3.Gpa}");  // Grace Hopper: 4.0
```

Three objects, one class. Each `new Student()` creates a separate object in memory. Changing `student1.Gpa` does not affect `student2.Gpa` — they are independent instances.

## Reference Types vs Value Types

Objects created from classes are **reference types**. The variable does not hold the object directly — it holds a **reference** (a pointer) to where the object lives in memory:

```csharp
Student a = new Student();
a.Name = "Ada";

Student b = a;        // b points to the SAME object as a
b.Name = "Changed";

Console.WriteLine(a.Name);  // Output: Changed — both variables reference the same object
```

This is different from value types like `int` and `double`, where assignment creates an independent copy:

```csharp
int x = 10;
int y = x;   // y gets a COPY of the value
y = 99;
Console.WriteLine(x);  // Output: 10 — x is unchanged
```

When you create an object with `new`, all properties start at their type's default value:

Always assign meaningful values to properties after creating an object. Relying on default values (especially `null` for strings) leads to runtime errors.

## Passing Objects to Methods

Objects can be passed as arguments to methods, just like any other type. The method receives a reference to the object — not a copy:

```csharp
Student ada = new Student();
ada.Name = "Ada Lovelace";
ada.Id = 1001;
ada.Gpa = 3.9;

DisplayStudent(ada);

static void DisplayStudent(Student s) {
    Console.WriteLine($"Name: {s.Name}");
    Console.WriteLine($"ID:   {s.Id}");
    Console.WriteLine($"GPA:  {s.Gpa}");
}

class Student {
    public string Name { get; set; }
    public int Id { get; set; }
    public double Gpa { get; set; }
}
```

Instead of passing three separate parameters (`string name, int id, double gpa`), you pass one `Student` object. The method accesses the data through the dot operator. This is a direct improvement over the parameter-heavy methods from earlier weeks.
