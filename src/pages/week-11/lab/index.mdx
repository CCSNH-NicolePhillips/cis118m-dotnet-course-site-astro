## Mission Objective

Build a **Calculation Engine** where all computations are performed by return-type methods. You must demonstrate the ability to:

1. Declare methods with typed return values (`int`, `double`, `string`)
2. Use the `return` keyword to deliver computed results
3. Capture return values in variables at the call site
4. Use captured results in further computation and display

Your program will contain **three return-type methods**, each performing a specific calculation. Every method must be called from `Main` **at least twice** with different arguments, and every return value must be captured in a variable.

## Method Signatures

Your required method signatures — do not change these:

```csharp

static double CelsiusToFahrenheit(double celsius)
static string FormatFullName(string firstName, string lastName)
```

---

## Result Capture Pattern

Every method call must follow this pattern — call the method, capture the result, then use it:

```csharp
int area = CalculateArea(10, 5);             // Capture the returned value
Console.WriteLine($"Area: {area} sq units");  // Use the captured value
```

Do NOT do this:

```csharp
// WRONG — calling without capturing means Main has no access to the result
CalculateArea(10, 5);

// WRONG — printing inside the method violates the separation of concerns
static int CalculateArea(int length, int width) {
    Console.WriteLine(length * width);  // Do NOT print in a return method
    return length * width;
}
```
